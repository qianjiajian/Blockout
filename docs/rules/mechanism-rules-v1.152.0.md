# 每日挑战成功后禁重挑战与完成勾选 v1.152.0

- Rule ID: `blockout-rules-v1.152.0`
- Runtime profile: `revised-2026-09-27-v1.5`
- Frozen on: 2026-10-07
- 完整承继 v1.151.0 及历史合同；以下只修订每日挑战成功后的再次进入与完成展示，并统一奖励卡显示来源，旧锁定文档不改。

## 用户本轮要求

- 每日挑战不允许再次挑战；当天已经挑战成功的关卡隐藏挑战按钮，和每日任务一样显示绿色打勾。
- 每日挑战成功结算的奖励卡数量与难度选择界面一致，使用同一 `DAILY_CHALLENGE_REWARDS` 配置。

## 执行口径

- 限制按当天固定抽取的难度档执行：当日某一难度挑战成功并完成结算后，该难度当天不可再次开始；完成状态使用既有 `completed` 标记。完成行隐藏挑战按钮和对应输入命中区域，显示每日任务同款绿色勾选；入口和核心开始逻辑均须拦截已完成难度，拦截不扣挑战次数。
- 失败、退出或尚未成功时重开，仍按既有每日5次和进入预扣规则执行；此次不禁止未成功关卡的重试，也不返还已消耗次数或道具。
- 完成状态与当天抽取、奖励标记沿用北京时间 UTC+8 的日键，在北京时间00:00刷新；次日各难度重新可挑战。在线、离线、设备时区差异与时钟回拨保护继续遵循 v1.151.0。
- 跨零点进行中的挑战仍使用开局日的关卡与结算归属；旧日成功不把新日同难度标为已完成，不阻止新日挑战。
- 难度1奖励金币50、灵感20；难度2金币100、灵感50；难度3金币200、灵感100。难度选择页与成功奖励卡统一读取该难度的 `DAILY_CHALLENGE_REWARDS`，此次只统一显示来源，不改变实际奖励账务、首次成功发奖和防重复发奖事务。
- 已完成状态继续用于防止重复发奖；旧已完成记录直接按完成态展示，不为恢复按钮、刷新界面或再次处理结算而清除完成标记、补发奖励或额外扣次。

## 不变范围与验收

- 保持三档各10关、每日每档固定1关、玩家独立种子、当天机制阶段冻结、关卡时间和道具规则；每日固定5次、北京时间零点重置、主线进度及主线奖励边界不变。
- 核验三档成功后按钮隐藏与绿色勾选、点击旧按钮区域和直接调用开始入口均不再开局或扣次、关闭重开后完成状态保持；未成功难度仍可按剩余次数进入。
- 核验北京时间零点与离线跨日后恢复可挑战、跨日旧局不占新日完成标记，以及奖励卡和难度选择页三档数量一致、重复结算不再发奖。
- 规则登记不代表实现或验收完成，实际状态与证据见 `docs/rules/WORKSTATE.md`；不访问真实玩家存档，不打微信包、上传或发布。
