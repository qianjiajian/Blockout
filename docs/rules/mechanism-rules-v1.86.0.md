1. 新棋盘采用 5×6 满矩形（30 个可玩格），以源实际色块足迹为容量基准，移除源开局未占用的中央颈空格；这使轮廓明显区别于 5×8 双腔狗骨形，同时不删减任何源色块或机制实例。

4. 第20关是卷帘首教关，按“新机制首教/低压”规则归入简单档，必挪合同为 **5–10 次**（含端点）。原 75 秒时限、reward85、parMoves24、实际三星门槛和首教文案保持；parMoves 只有在新完整路线验证不可达时才可同步为已验证总拖数，并需单列证据。
