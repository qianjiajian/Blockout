# 旅程任务以通过指定关卡为达成条件 v1.189.0

- Rule ID: blockout-rules-v1.189.0
- Runtime profile: revised-2026-09-27-v1.5
- Frozen on: 2026-10-10
- 完整承继v1.188.0及历史合同；本次明确旅程奖励任务的通关语义与显示一致性，不改变棋盘runtime。

用户要求：“旅程中任务达成条件改成通过关卡，而不是到达关卡”。

- 旅程奖励任务以主线通过指定关卡的已确认记录为依据；仅解锁、到达或进入该关，不构成任务达成。保留现有真实通关记录与存档归一化来源，不凭当前选中关号、最高可进入关号或其它模式成绩发放奖励。
- 奖励任务卡明确显示“通过关卡”及固定目标关号，奖励弹窗显示“通过第N关”，未完成时提示通过该关后领取。任务目标不得被当前旅程位置替换，例如玩家当前在16关时，15关奖励仍显示通过15关。
- 实际代码的奖励资格与待领事件此前已按通关记录判断，本轮须核对并保持其统一；修复显示不一致不冒称新增已存在的判定。红点、领取按钮、未达提示均与同一通关资格一致。
- 已领取记录和已发资源保持，不追扣或重发；原奖励种类、数量、候选保存确认与未知状态重试、音效及飞行动画保持。
- 旅程当前位置、滚动定位、章节背景解锁与选择、功能入口解锁维持既有合同；本次任务条件不将章节背景切换整体后移一关。主线200关、每日挑战和荣耀联赛等其它系统保持。
- 使用隔离数据验证未通关不可领取、通关可领取且不重复、旧领取记录保留、目标关号稳定。不得访问真实玩家存档，不自动微信打包、上传或发布。旧锁定文档、校验值与旧验收证据保持。
