## 入口和保存边界

- 以已确认保存的主线完成进度判断。最高已解锁主线关号大于N或已有N的首通记录可确证达标；不能用当前浏览/回放/临时测试关号或每日/联赛关号解锁。
- 未解锁入口保留可发现性并显示锁定与通关条件，点击说明条件，不能进入、购买或新开局；底部导航、顶部金币快捷入口和其它相同目的入口统一门槛。已解锁后回看早关不重新上锁。
- 既有金币、库存、任务与成就进度、领取记录、每日次数和关卡选择均保留，不因加门槛而清空、退款或重复发奖。保存未知的既有候选继续原事务重试，不重新构造奖励。
- 商店入口门槛不改变冻结/火箭/脉冲等道具本身的解锁与首教关号；关内已有道具和教学继续原规则。
- 旅程入口门槛不推迟既有章节背景解锁：通关10后的新背景自动应用与亮相仍正常，并可确认；仅手动旅程访问/背景选择/领奖受新门槛约束。
- 每日挑战只对新开局/重开加门槛，不改变既有活动会话归属；已有局的结束、退出与保存处理保持，不能误当主线结算。未满足新门槛的旧进行局退出后回首页。
- 本轮先落实解锁条件与锁定显示；不将上轮完整功能引导方案视为已实现，不新增成就/每日任务引导。以后功能解锁引导必须排除这两项。
- 使用隔离存档及真实Pointer验证边界、其它入口、旧高进度回放和未解锁不扣资源；不访问真实玩家存档、不重打微信包、上传或发布。
