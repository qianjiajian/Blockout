- 只调整最终主线第7关的上方通道布局，不改变棋盘尺寸、可玩格、色块数量、形状、出口数量、出口颜色、冻结计数、时间、奖励或三星数据。

- 粉色 `cc-piece-04` 仍是唯一初始可进入顶部粉色出口的开局块。它离场后，上方红色阻挡块和黄色目标共同封住第二个粉色块的通路，普通操作无法完成剩余棋盘，形成真实无道具死局；不再依赖把粉色块移动到出口的旧绕行路线。
- 火箭目标仍为黄色 `cc-piece-03`，其死局入口坐标为 `[1,0]`。移除该目标后，已验证的剩余布局存在完整通关路线。

## 火箭救援触发

- 粉色开局出口动作结算、棋盘无任何可用出口且本局至少完成一次有效动作后，立即允许第7关火箭救援引导；暂停、后台、转场、动画未结算、失败、通关和重开时不触发。
- 引导不再把目标坐标当作死局成立的硬条件，目标仍在初始位或玩家将其拖到其它合法停靠位时都能正确指向当前目标。未解锁火箭或可用库存为0时不触发。
- 第一阶段手指指向火箭按钮；火箭成功使用后第二阶段指向当前 `cc-piece-03`。现有本局预留、撤销、成功结算扣除、失败/重开/离开退款及重复进入重触发规则保持。
