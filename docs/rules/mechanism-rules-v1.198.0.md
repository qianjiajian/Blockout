# 每日挑战必挪验收允许正负3次 v1.198.0

- Rule ID: blockout-rules-v1.198.0
- Runtime profile: revised-2026-09-27-v1.5
- Frozen on: 2026-10-12
- 完整承继v1.197.0及历史合同。本轮仅调整当前每日挑战300关制作的必挪数值验收容差；主线、联赛、实际计时、三星和奖励合同不因此改变。

用户要求：“每个关卡在求解时，如果必挪次数上下限正负3以内，都可以接入正式关卡”。结合当前每日挑战正式制作任务，允许每档原数值下限减3、原有限上限加3（含端点）。

## 当前每日挑战的数值范围

| 难度 | 原目标 | 本轮允许接入范围 |
| --- | --- | --- |
| 难度1：难 | 16–20 | 13–23 |
| 难度2：超难 | 21–30 | 18–33 |
| 难度3：超超难 | 大于30，即至少31，无有限上限 | 至少28，且有完整通关路线的有限上界 |

- 名称、难度槽位与原目标保留；允许范围重叠不自动改档，不把同一布局复制到其它档位凑数。
- 这里是档位边界的正负3容差，不是要求证明区间U−L小于等于3，也不是给实际L或U加减3。证明仍记录真实数值。
- 难度3原来没有有限上限，本轮也不新增上限；仍须无道具完整通关见证，不能接受无穷或未知U。

## 求解与正式接入

- 新输入的下界求解目标、完整路线上界检查及正式注册表检查统一采用上述允许范围。有效下界L不得低于允许下限；完整原关卡路线U不得高于允许的有限上限，且L≤U。
- 既有同对象的有效L与完整U若满足本轮容差，可做新规则复核并接入；复核单独记录，旧FAIL、旧规则证据、旧哈希和原始数值保持，不能原地重标通过。
- UNKNOWN、预算耗尽而未证明、L或U缺失、没有完整路线均不因本轮容差视为通过。完整库存、原关卡路线与机制验证仍适用。
- 每个布局每次上下界求解最多10000个完整棋盘状态及历史失败身份防重试规则保持。不得以换规则版本、改关号或改档位重刷旧失败图；需要继续求解时仍须真实换色换形及必要重排。
- 旧冻结数学实现与历史工具不改写。新增版本适配器显式传入容差目标，并绑定新规则与共用数值策略；不改引擎成本定义、计数或预算来制造通过。

## 其它验收与执行范围保持

- 独立布局、主线棋盘改编、原向素材、满铺与隐藏层、来源差异、机制实际参与、真实下界和完整路线、正式双屏Pointer与自然计时验收保持；本轮没有取消任何非数值质量门禁。
- 按机制解锁顺序制作：先补齐基础合并阶段每档10关、合计30关，再依次继续其它阶段；总目标300关，合格一关接入一关。已正式接入的关卡保持，不将历史已选设计数量冒称正式数量。
- 每日5次、北京时间0点重置、成功不可再挑战、奖励及主线边界保持；尚未完成的运行接入另按实际证据记录，不将规则登记当作制作完成。
- 本轮不访问真实玩家存档，不自动微信打包、上传或发布；v1.197另一个已授权微信本地优化任务的范围与证据独立保持。
