# Daily Tasks V1 ImageGen prompts

All four generations used the built-in ImageGen tool. The raw generated sheets are retained beside the independently replaceable source PNGs described in `README.md`.

```text
Create one standalone mobile casual puzzle game UI icon asset for a DAILY TASKS home-screen shortcut. Match a premium cheerful 3D toy-like fantasy puzzle game style: glossy royal-blue circular medal/button, thick beveled rim, small golden calendar page with a green checkmark and one tiny sparkling star, readable silhouette at 80 px, soft studio lighting, saturated but harmonious blue/gold/green palette, clean rounded geometry, subtle depth and highlights. Transparent background, isolated centered object, generous 8% transparent padding, no drop shadow beyond the object bounds. Absolutely no text, letters, numbers, words, logos, watermark, UI frame, screenshot, or background. Square 512x512 PNG-style sprite, front-facing, production-ready.
```

Keep the center and right title area intentionally empty for runtime text.
```text
Style/medium: premium polished 3D toy-like casual mobile puzzle-game UI, soft bevels, chunky readable shapes, clean product-render finish, matching the supplied game assets.
Composition/framing: isolated horizontal component, approximately 3.75:1 aspect ratio and intended for a 360x96 runtime slot; centered banner body; ornament contained near the left edge without covering the central text-safe area; only minimal transparent padding; entire silhouette visible and uncropped.

Constraints: one component only; no outer popup panel; no button; no card grid; no text; no letters; no numbers; no UI copy; no logo; no watermark; no cast shadow beyond a compact soft halo; preserve a large empty text-safe center.
Avoid: opaque background, checkerboard background, scene backdrop, full-screen mockup, Chinese characters, English words, numerals, ribbons with writing, clocks, lock symbols, excessive sparkles, asymmetrical cropping.
```

## Five task icons

```text
Use case: stylized-concept
Asset type: production sprite sheet of five daily-task icons for a polished mobile casual puzzle game
Primary request: Create ONE strictly horizontal 5-cell icon sprite sheet on a genuinely transparent background. The sheet must contain exactly five separate icons, one icon per equal cell, ordered left to right:
1) level-completion flag: a jaunty royal-blue and violet finish flag on a short gold-tipped pole, celebratory but no writing;
2) gold star: one large polished five-point golden star with a soft blue-violet rim glow;
3) three-star crown: a compact royal gold crown with blue-violet velvet and exactly three small golden stars arranged above it as part of the emblem;
4) no-booster shield: a sturdy sapphire-blue shield with violet edging and a simple clean gold protection emblem, communicating an unassisted/no-booster challenge without text;
5) magic booster: a compact magical blue-violet power orb with small gold fins and sparkling energy, clearly a game booster but not a rocket already used elsewhere.
Style/medium: premium vibrant 3D toy-like mobile game iconography, rounded bevels, glossy enamel, tactile gold trim, coherent lighting and material treatment across all five icons.
Composition/framing: exact 5 columns x 1 row; five equal square logical cells; each icon independently centered at identical visual scale with generous safe padding; no icon crosses into another cell; no overlap; no visible cell dividers, panels, circles, badges, card frames, or background shapes.
Lighting/mood: cheerful studio lighting, crisp readable silhouette, subtle self-contained glow that does not touch adjacent cells.
Color palette: unified royal blue, violet-purple, warm polished gold, and small white highlights.
Background: actual transparent alpha across the whole sheet, including all gutters.
Constraints: exactly five icons in the stated order; transparent background; no text, no letters, no numbers, no watermark, no logo, no UI labels; do not crop any icon, shadow, star, or glow; keep each icon isolated inside its own fifth of the canvas.
Avoid: opaque or checkerboard background, gradients filling the canvas, scene illustration, visible grid lines, extra icons, duplicate icons, photorealism, flat vector style, red-dominant colors.
```

## Reward chest states

```text
Primary request: Generate ONE horizontal sprite sheet with EXACTLY three equal square cells in a single row, showing the SAME reward chest in three clearly distinct states, left to right: (1) closed and locked, calm and unavailable; (2) closed but brightly glowing and ready to claim, with magical golden-blue light around the seams and clasp; (3) lid fully open and already claimed, interior visibly empty with only a gentle residual sparkle.
Subject: a premium toy-like treasure chest with a deep purple-to-royal-blue lacquered body, thick polished gold trim, rounded corners, and one prominent gold five-point star-shaped clasp. Preserve the same chest design, camera angle, proportions, materials, and scale across all three cells.
Style/medium: polished vibrant 3D casual-game UI icon, friendly mobile puzzle game, chunky toy proportions, clean bevels, glossy materials, crisp silhouette, professional production asset.
Composition/framing: strict 3:1 transparent canvas; exactly three equal square slots; one chest independently centered in each slot; identical visual scale; generous equal transparent padding; no overlap or visual spill between cells; no divider graphics; straight-on three-quarter view.
Lighting/mood: soft studio key light; state two has the strongest magical glow; state one subdued; state three celebratory but clearly completed.
Background: genuine fully transparent alpha background in every empty pixel; no colored rectangle, no checkerboard, no scene.
Constraints: exactly three chests and exactly three cells; left locked, middle ready, right open; same chest identity; all objects fully contained within their own square; preserve clean transparent edges suitable for cropping; no text, no letters, no numbers, no UI labels, no badges, no external card frames, no coins, no loot, no characters, no logos, no watermark.
Avoid: opaque background, gradient backdrop, floor plane, accidental fourth object, overlapping cells, inconsistent chest design, different camera angles, tiny chest, flat vector art, photorealism.
```
