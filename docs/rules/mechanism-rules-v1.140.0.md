本轮用户反馈“第7关怎么火箭没解锁”，并补充要求“挑战关卡时，点击右上角的暂停按钮，背景音乐也正常播放”。本版本只修正第7关进入时的火箭可用判定，以及暂停面板的挑战背景音乐场景；不改变解锁等级、库存、价格或关卡结果。

## 第7关火箭解锁判定

- 火箭的教学解锁等级仍为第7关，低于第7关的挑战仍显示锁定并拒绝使用。
- 进入正在挑战的第7关时，即使旧存档的 `highestLevel` 仍记录为上一关，当前关卡也计入道具解锁判定，火箭按钮显示可用并可触发既有死局救援。
- 商店、主城和其它非挑战界面仍只按持久化 `highestLevel` 判断，避免仅浏览或错误跳关提前发放商店权限；库存、火箭预留与成功通关才扣除的规则保持不变。

## 挑战暂停时的背景音乐

- 挑战中点击右上角暂停后，保持当前关卡的背景音乐正常播放；剩余时间不推进，倒计时警示音、棋盘动画和其它挑战动效不在暂停期间触发。
- 暂停时根据暂停瞬间的剩余时间继续使用 `gameplay` 或 `danger` 场景，恢复挑战后沿用同一场景继续播放，不重置音乐进度。
- 结算失败、通关和其它既有场景的音乐映射保持不变；后台隐藏仍按既有宿主生命周期处理。
