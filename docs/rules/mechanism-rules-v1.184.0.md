# 福利站激励广告补给 v1.184.0

- Frozen on: 2026-10-10
- 完整承继v1.183.0及历史合同，以下商城变更优先。

用户要求将商城改为看广告领取奖励，已看过完整方案及ImageGen效果图后明确“采纳，开始制作”。按该方案和效果图实现福利站，以下为本轮采用的首版参数，不采用未向用户呈现的其它候选额度。

## 界面与补给

- 原商城入口及功能解锁卡片改称“福利站”，仍通关第8关解锁，沿用原先卡片退出再手指的引导次序，不重置旧已读记录。
- 参考已采纳效果图的紫金头部、蓝紫菱格背景、奶油卡片、绿色视频领取按钮；顶部显示金币/灵感/体力，四类卡按灵感、金币、体力、自选道具排列。小屏可滚动，原底部五栏导航保持。
- 每次灵感10、金币100、体力1、自选道具1；四类各每日2次，道具冻结/火箭/脉冲共用2次额度，可重复选同一种。因此每日最多8次。
- 北京时间零点刷新次数；成功领取后所有福利站广告共用60秒冷却。道具须已解锁且库存不足9；体力开始领取时须不足5，广告期间自然恢复到满仍兑现承诺的1点，允许奖励溢出。
- 灵感卡关联首幅已解锁未收藏名画的差额，足够50灵感时可主动去收藏，仍由玩家手动花费50灵感修复；不因领取灵感直接解锁关卡、授予名画或扣灵感。原名画翻转合同保持。
- 商城内金币购买替换为广告领取；关内金币购买道具、金币补体力及原其它收支保持。

## 广告与领取

- 仅用户明确点击“看广告领取”后请求广告，加载时阻止重复操作；完整观看由微信广告完成回调确认，不以计时器或点击按钮冒充成功。中途关闭、无填充和加载错误均不发奖、不扣次数、不开始冷却。
- 同次完成只发一次奖励；奖励到账与次数/冷却记录使用既有候选保存确认事务。保存拒绝或未知时保留同一待确认候选，不要求再次看广告、不重算或重复授予；恢复时核对持久候选记录。确认到账后才播放已有领奖音效及资源动效，更新卡片状态。
- 请求开始时锁定领取日和道具选择，跨北京时间零点仍按该请求批次处理。日键采用单调观察保护，设备时间回拨不得重新刷额度；本地时间机制不冒称服务器防作弊。
- 宿主需提供真实激励广告接口及广告位配置。当前广告位ID待用户提供；未配置或不支持的环境显示广告暂不可用，不制作面向玩家的伪广告或绕过发奖。隔离测试可用明确的模拟宿主验证完成/取消/错误回调，但不得声称真广告验收。

## 边界与验证

- 新增福利站领取账本需兼容旧存档默认空额度记录，不覆盖余额、进度、道具、收藏所有权或功能已读信息。后台返回不重复发奖，重复回调、跨日、库存满、保存拒绝/未知及重载应验证。
- 原主线/每日/联赛关卡、经济其它收支、关内金币购买、收藏50灵感及全部历史规则保持。全屏福利站不套非全屏弹窗缩放，实际新增小弹窗沿用v1.181动画。
- 本轮制作并更新本地Web，真实微信广告接入以有效广告位和实际回调验证为准；不自动微信打包、上传或发布，不访问真实玩家存档。工作进度与证据记录在WORKSTATE，不将规则登记当作完成。
