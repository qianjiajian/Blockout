# 关卡内道具购买与统一单价 v1.160.0

- Rule ID: blockout-rules-v1.160.0
- Runtime profile: revised-2026-09-27-v1.5
- Frozen on: 2026-10-08
- 承继v1.159及历史合同；本版仅覆盖道具购买入口、每次购买数量和全游戏道具售价的下述变更。其余关卡、解锁、经济、保存及发布边界保持。

## 用户已确认范围

- 道具数量为0时，点击关卡底部道具入口，弹出参考图形式的购买界面。
- 每次购买1个道具。全游戏统一售价：冻结300金币、火箭400金币、脉冲400金币，包含原商店与新增关卡内购买。
- 本次明确的单个购买数量与价格取代参考图中的3个展示，以及讨论阶段的3个一组或统一900金币等未采用方案。不得将参考图数值当成最终购买规则。

## 实现约定

以下为落实本次需求并保持既有运行边界的实现约定，不冒称用户逐项原话。

- 关内购买入口仅供已解锁且可用数量为0的道具。继续沿用冻结第4关、火箭第7关、脉冲第10关的既有道具资格判定；未解锁时保留等级提示，不得购买或使用。该弹窗独立于主界面商店的通关8门槛，不为关内补充已解锁道具额外要求进入商店。
- 购买面板展示对应道具、效果、数量1与当前统一价格。效果不改：冻结仍为10秒，火箭与脉冲沿用现有资格及效果；购买本身不自动使用道具、不自动选目标、不改棋盘、不替代开局扣费。
- 弹窗展示期间暂停关卡计时并阻挡底层关卡操作；关闭或完成购买后恢复原关卡，重置计时基准，不补扣停留或后台时长。已有暂停按钮的通关5开放规则不因此改变。
- 单笔成功购买原子地扣除对应金币并增加1个库存；金币不足、未解锁或库存达到9时不扣款、不增加库存。不购买部分数量，不降低已有超额库存。原商店仍每次购买1个，只同步统一单价。
- 使用既有候选保存事务：先计算候选账户，再保存与核对；只有确认持久保存成功后才将交易作为完成放行。失败不发货、不额外扣款；保存状态未知时保留原始baseline、完整candidate及对应道具、数量、价格，重试同一候选，不重新报价、不重算、不重复发货或扣款。
- 保存未确认时阻挡关闭或其它会覆盖该候选的交易与页面操作。前后台、体力自然恢复、每日周期与联赛刷新不得覆盖未确认购买候选；原有保存恢复与模式隔离继续保持。
- 不追溯重价或重置已有玩家金币、道具和进度。已创建的未确认购买候选仍按其原记录核对，不以新单价重新扣款。主线、每日与荣耀联赛的关卡和奖励数据均不因本次改变。

## 验证与交付边界

- 核验三种价格、单个入库、金币不足、库存上限、未解锁、关内暂停/恢复、保存拒绝与未知重试，以及不自动使用、不误触底层关卡。同步原商店显示和交易、相关经济统计及十种语言文案。
- 使用隔离内存或合成存档验证，禁止访问或修改真实玩家存档；通过相关检查后可更新本地Web，不重打微信包、不上传或发布。
- 本文件是规则合同，不是完成报告。实施状态、测试与真实Pointer证据另记WORKSTATE；历史规则文档、校验值和既有验收报告保持不变。
