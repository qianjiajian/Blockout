## 用户授权

用户要求：“冻结道具解锁后，如果一次都没使用过冻结，无论在哪一关，倒计时还剩最后20秒时，出现手指引导点击冻结道具”，并补充“没有解锁时，不触发引导”。

冻结道具按现有time道具处理。玩家最高已解锁关卡达到冻结解锁关后，在任意主线关卡的有效进行状态下，只要剩余时间不超过20秒、库存仍有冻结且持久记录中从未成功使用过冻结，就显示指向冻结按钮的手指和按钮高亮。该提示不阻塞棋盘操作，点击原冻结按钮即可使用。

手指提示只在前台有效计时状态推进；暂停、后台、冻结生效期间不推进动画，也不触发额外音效。失败、通关、重开或离开本局清除本局提示；同一局在未使用前只触发一次，下一局仍按持久使用记录判断。成功使用冻结后记录time已使用并永久停止该提示；撤销冻结不会清除已使用记录。未达到冻结解锁条件时不触发提示。

新增记录仅用于提示资格，不改玩家库存、计时扣除、星级判定、失败逻辑、关卡数据或存档中的其他字段。继续复用现有冻结按钮命中区域和 onboarding 手指素材；不新增外部美术资源。本轮不打包、上传或发布。
