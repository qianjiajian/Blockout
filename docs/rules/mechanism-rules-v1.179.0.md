# 非全屏弹窗回弹与放大阶段淡入 v1.179.0

- 完整承继v1.178.0及历史合同；以下只取代v1.178的缩放曲线、淡入阶段和执行时长。

用户追加明确：所有非全屏弹窗从80%放大到120%，再从120%缩小到100%。随后进一步明确，淡入效果发生在80%到120%的放大期间。因此，放大阶段不透明度从0%到100%；回落阶段始终保持100%不透明度。

执行配置采用0.32秒：前0.18秒三次缓出，缩放80%→120%、不透明度0%→100%；后0.14秒平滑回落120%→100%，不透明度固定100%。这些时长和具体缓动函数是执行选择，用户指定的是缩放关键值与淡入所属阶段。采样、绘制和交互门禁共用同一生命周期；完成回落后恢复原点击区域。减少动态时直接终态，后台停止推进，关闭重开和另一张连续卡片重新播放，窗内切换/重试不重播，父子弹窗独立。

v1.178的全部弹窗覆盖、全屏排除、固定背景/遮罩/金币高亮、原生改名输入延后、名画翻转等既有表现保留；v1.177功能解锁仍为前置卡片→点击“去看看”→入口手指。保留段位显示与滑动以及全部关卡、经济、保存、奖励和解锁合同；不访问真实玩家存档，不微信打包、不上传发布。旧规则文档、hash及旧动画测试报告保留，不把旧80%→100%证据冒称为本版回弹验收；最终进度见WORKSTATE。
