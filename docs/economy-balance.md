# 历史：100 关经济、道具与体力节奏

> 本文由正式关卡、Journey 里程碑奖励与道具配置自动生成。固定金额与购买力只按每关各完成一次计算，不把普通关的重复完成产出纳入有限总额。修改奖励、价格、解锁关卡或全赛季报告后，运行 `pnpm docs:economy` 更新；`pnpm docs:economy:verify` 会拒绝漂移。

## 上线口径

- 前 3 关只训练拖拽、转向和让路，不开放捷径型道具。
- 加时在 Lv 4、火箭在 Lv 7、脉冲在 Lv 10 逐个开放；重玩低关时按账号最高进度保留已解锁道具。
- 新档自带 1000 金币和每种 3 个道具，共 9 个；这是容错储备，不要求玩家首日购买。
- 每次有效完成普通关都发当前关 `level.reward` 基础金币；重复完成仍发基础金币，但不重复首通进度或 Journey 解锁。
- 100 关各完成一次的基准金币共 13,505；加初始金币后，有限基准钱包为 14,505（尚未计 Journey）。普通关的重复完成收入不计入该固定总额。
- Journey 金币里程碑另发 50 金币，计入后合计钱包为 14,555；Journey 还免费发放 8 个道具（加时 ×3、火箭 ×2、脉冲 ×3），免费道具不折算为金币或购买力。
- 三种道具均价 210，合计钱包可买约 69 个均价道具，平均每 1.45 关一购；连同初始库存和 Journey 免费道具，理论道具辅助容量为 86 次。免费道具受库存上限（加时 9、火箭 9、脉冲 9）约束，只有及时使用、避免满仓时才能全部兑现。
- Journey 体力权益另计：0 次免费体力，以及 4 次无限体力（共 10,800 秒 / 180 分钟）；体力权益不折算金币、购买力或道具辅助次数，也不与 86 次道具辅助相加。
