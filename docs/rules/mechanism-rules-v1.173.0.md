# 个人外观解锁条件移至保存按钮位置 v1.173.0

- 完整承继v1.172及历史合同；本条仅覆盖v1.166的锁定草稿灰色保存按钮、目录关卡条件文字，以及v1.167的底部不显示解锁提示约定。

用户要求：个人资料未解锁头像和头像框的目录项不显示“通关X”；选中未解锁项时隐藏保存按钮，在按钮原位置显示“通过X关解锁”。该界面调整已获明确执行授权。

头像与头像框目录均移除单项关卡条件文字，保留原角落锁标、完整清晰的图片、选择圈及组合预览。未解锁项仍允许选中预览，预览不提前装备、不扣费、不写存档。

当前草稿头像或头像框任一尚未解锁时，隐藏保存按钮的底图、按钮文字、按压效果和点击目标，在原保存按钮位置显示非交互文字“通过X关解锁”；英文采用“Complete level X to unlock”。两项草稿均达到原主线通关资格时恢复既有保存按钮。执行约定：X取当前组合中尚未满足的解锁关号最大值；若切到另一分类，仍检查完整头像与头像框草稿，不能绕过锁定选择或错误显示可保存状态。此规则只选择提示数字，不增加或改变任何解锁条件。

保留25款头像、19款头像框、原15头像与9框免费、其余原主线指定关卡通关门槛及旧玩家自动资格。动作层保存仍复核两项解锁资格，未知保存仍按原候选重试，重试界面和输入门禁优先，不因当前预览提示而替换候选、遮掉必要重试或冒称已保存。拒绝不提交；确认保存成功后保留当前选择页、滚动位置、选中项及既有成功反馈。改名流程与费用保持。
