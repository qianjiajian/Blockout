2. 设备本地处理的信息及用途

  • 玩家资料：随机生成的本地玩家编号、默认或您输入的昵称、选择的内置头像和头像框、首次建立资料的时间。用于本机资料展示；编号不是广告标识符，也不是联网注册账号。本版不要求真实姓名、手机号或邮箱，不上传照片。
  • 游戏存档：关卡进度、最佳星级和步数、尝试及连胜记录、游戏内金币、体力和道具、收藏、旅程、成就、每日任务及挑战、联赛和排行相关状态、领取记录与计时数据。用于保存游戏进度、计算恢复时间、任务及游戏内奖励。
  • 设置：游戏语言、音乐和音效、曲目、震动及减弱动画等选择。首次启动时在本机读取设备提供的语言偏好，以选择默认游戏语言。
  • 本地排行显示：当前版本未配置联网地区识别服务。显示用地区可由程序随机分配并保存，不代表读取 GPS 或识别您的真实住址；模拟排行数据在设备上生成，不向其他玩家广播您的昵称或成绩。
  • 运行信息：为适配显示和排查启动问题，应用会在本机使用显示尺寸、系统及 WebView 版本等运行信息，并可能将版本、加载失败或崩溃信息写入 Android 本机诊断日志。本版不自动上传这些日志。
  • 复制操作：您主动使用资料页的复制功能时，应用会尝试将选定的本地玩家编号写入系统剪贴板，不读取剪贴板中的其他内容。系统输入法和剪贴板的自身处理由您使用的系统或输入法决定。

上述存档通过应用内 WebView 的本地存储保存在设备上。它们不是“完全不处理任何数据”；但在本草稿所限的离线测试版中，应用不将这些资料发送给开发者或广告、统计服务。

3. 联网、广告和第三方服务

本离线基础测试版不启用 INTERNET 权限，不接入聚合广告、Google Mobile Ads、Firebase Analytics/Crashlytics 或 Solar 统计 SDK，不提供云存档、联网登录或真实广告展示。游戏资源随安装包提供；本地资源加载地址不表示向外部网站传输资料。应用使用 Android 系统 WebView 运行内置游戏内容。

您主动点击“隐私政策”时，应用调用外部浏览器打开上述公开网页；浏览器访问网站会按其自身方式处理网络信息（包括可能向网站或托管服务提供 IP 地址）。这不是游戏在后台上传存档。您主动点击联系邮箱时，应用尝试打开邮件应用；由您决定是否发送及发送内容。应用不会自动附加玩家编号、存档或诊断日志。外部浏览器和邮件应用的网络权限独立于本游戏。

Google Play、Android 系统、设备厂商或输入法在自身服务中处理的信息，不由本应用的离线实现决定，应另行查看对应服务的说明。如未来加入联网或第三方 SDK，必须重新核对实际数据流、更新本政策及商店 Data safety 信息，并在适用时取得用户同意。

4. 保存期限、删除和安全

2. Information processed on your device

  • Player profile: a randomly generated local player number, a default or player-entered nickname, a selected built-in avatar and frame, and the time the profile was created. These support the local profile display. The number is not an advertising identifier or a registered online account. This build does not require a real name, phone number or email address, and does not upload photos.
  • Game saves: level progress, best stars and moves, attempts and win streaks, virtual coins, energy and items, collection, journey, achievement, daily task and challenge records, league and ranking state, reward records and timestamps. These maintain progress, timers and in-game rewards.
  • Preferences: language, music and sound, selected tracks, vibration and reduced motion. On first launch, the app reads the language preferences provided by the device locally to select a default language.
  • Local ranking display: no online region lookup service is configured for this build. A display region can be randomly assigned and saved; it is not GPS location or your actual address. Simulated ranking data is generated on the device. Your nickname and scores are not broadcast to other players.
  • Runtime information: display dimensions and Android/WebView version information are used locally for display compatibility and startup diagnostics. Version information, loading failures or crash details may appear in Android's local diagnostic logs. The app does not automatically upload these logs.
  • Copy action: when you choose the copy action on the profile page, the app attempts to write the selected local player number to the system clipboard. It does not read other clipboard content. Your system and keyboard provider control their own input and clipboard processing.

Saves are kept in the application's WebView local storage on the device. This is local data processing, rather than an absence of all data processing. In the offline test build covered by this draft, the app does not transmit this information to the developer or advertising/analytics services.

3. Network access, advertising and third parties

This offline foundation test build does not enable the INTERNET permission or integrate mediation advertising, Google Mobile Ads, Firebase Analytics/Crashlytics, or Solar analytics SDKs. It has no cloud save, online sign-in or live ad delivery. Game resources are bundled with the installation; local asset URLs do not indicate transmission to an external website. Android's system WebView runs the bundled game.

Choosing the privacy-policy action opens the supplied website in an external browser. Browser visits can disclose network information such as your IP address to the website or its hosting provider; this is separate from uploading game saves. Choosing the contact action opens a mail application where you decide whether to send a message and what to include. The game does not automatically attach a player number, save file or diagnostic log. The browser and mail application have their own network permissions and data practices.

Google Play, Android, device manufacturers and keyboard services may process information for their own services under their respective notices. Their independent behavior is not determined by this app's offline implementation. Any future network or SDK integration requires a fresh data-flow review, updates to this policy and the Play Data safety form, and user consent where applicable.

4. Retention, deletion and security

Local saves normally remain until you clear the app's storage in Android settings or uninstall it and choose to remove its data. Menu labels vary by device. Clearing storage deletes local progress; the app has no server copy to restore. Android automatic backup is currently disabled for the app. Manufacturer migration tools, system data-retention options and backups you create must be managed separately.

This build has no online account: a local player number is not an account requiring a server deletion request. Saves are stored within the application's local storage. This notice does not promise protection after device loss, system modification or a user-made copy. Review any message, screenshot or diagnostic file before voluntarily sending it to the developer. The recipient receives the email address, text and attachments you choose to send.
