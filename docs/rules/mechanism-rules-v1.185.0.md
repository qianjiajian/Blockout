# 每日挑战逐关验收与正式接入 v1.185.0

- Rule ID: blockout-rules-v1.185.0
- Runtime profile: revised-2026-09-27-v1.5
- Frozen on: 2026-10-10
- 完整承继v1.184.0及历史合同；仅以下每日挑战接入顺序取代v1.154/v1.156中等待全量完成的要求。

## 用户最新要求

用户明确：“不要候选不要设计，只要达到要求的，直接写入正式数据，好一个写入一个。”

- 新每日目标仍为10阶段300关，每阶段三档各10关；基础六类合并与提前出现例外保持。
- 改为逐关完成验收、逐关写入正式数据，不再等待300关或某阶段30关全部齐备。已满足要求的原有对象优先验收和接入，不为增加新文件或候选数量重复制作。
- 不将“不要候选不要设计”解释为取消关卡质量、数学证明或真实运行验证，也不将未完成验收的文件改名为正式完成。

## 单关验收及运行

- 正常主线棋盘基准、独立布局、近似布局实际检查、机制强度和真实参与、原向素材、空间/满铺/隐藏层及完整库存要求保持。已有对象的有效证据可以核对后复用，不将历史失败改为通过。
- 难16至20、超难21至30、超超难下界至少31且有完整有限上界；有效下界及完整无道具路线须对应同一实际对象。每次上下界最多10000完整棋盘状态、耗尽后实际改颜色和形状等合同不变。
- 每关完成双屏真实Pointer、自然计时、全库存与实际结算验证后登记正式对象；接入后核对正式查询确为该对象及真实挑战入场。不能以候选覆盖入口的通过冒充正式注册表运行通过。
- 允许正式目录稀疏追加，未接入槽位不制造占位关、不重复一张图凑数。整池图册及跨关差异检查随接入持续完成，全部300关满足后才宣称目标完成。
- 新正式关卡进入新日对应阶段/难度的抽取范围。同日已选对象、进行局归属、次数、成功与领奖记录保持，不因追加关卡或修订目录重新抽取。为兼容既有当日对象保留旧目录；缺少新正式对象的阶段/难度可暂沿用旧正式目录，旧450不计入新300完成数。不得回退到未经每日认证的主线原关卡。

## 报告和保持项

- 完成数只统计已完整验收并接入的新版正式关卡。历史已选文件保留；用户询问历史数量时明确说明文件是否存在、尚缺何种验收，不把部分检查通过称作正式完成。
- 每日5次、北京时间零点、当日固定抽取、成功禁再挑战、三档奖励、主线库存与道具扣除规则、候选保存确认事务保持。
- 主线、联赛、福利站及其它经济与UI合同不变；不读写真实玩家存档，不自动微信打包、上传或发布。实际进度和证据写WORKSTATE，规则登记本身不计完成。
