# 正式八色积木

本目录包含项目方 `方块-空心-边框-冰-改/方块-空心-边框-冰-改/` 的
120 张正式 RGBA PNG，以及为当前关卡缺失轮廓保留的 35 张生成整块 PNG，
共 155 张。`pnpm art:optimize` 逐字节复制到运行目录；运行时禁止把多格
色块拆成一格图拼接。

项目方编号按下表映射为稳定英文文件名；编号是来稿编号，不是
`formalBlockShapes.ts` 的内部 shape id：

| 来稿实心编号 | 目标后缀 | 原始尺寸 |
|---:|---|---:|
| 1 | `single` | 95×104 |
| 2 | `vertical-2` | 95×199 |
| 3 | `vertical-3` | 95×294 |
| 4 | `horizontal-3` | 285×104 |
| 5 | `horizontal-2` | 190×104 |
| 6 | `l-triomino` | 190×199 |
| 7 | `s-tetromino` | 285×199 |
| 8 | `t-tetromino` | 285×199；橙/紫来稿为 285×200 |
| 9 | `square-2x2` | 192×199 |

外壳编号 1/2/3/4/5/9 分别映射 `shell-single`、`shell-vertical-2`、
`shell-vertical-3`、`shell-horizontal-3`、`shell-horizontal-2`、
`shell-square-2x2`，尺寸依次为 95×104、95×199、95×294、285×104、
190×104、192×199。绿色纵三外壳来稿误写为 `绿3v.png`，仍按编号 3 处理。

一格外壳是带透明开孔的 RGBA 叠加层，不是完整双色图；运行时必须先绘制
内层颜色的实心一格图，再按相同 95px 名义格原位叠加外层颜色的一格外壳。
中心 Alpha 允许保留来稿抗锯齿（0–4/255）。整块图水平方向居中，底沿对齐
名义占格底沿，多出的约 9px 立体厚度向上延伸；运行时按视觉底边从上到下
绘制，使屏幕位置更靠下的资源盖住靠上的资源。整图只允许旋转
0°/90°/180°/270°，不允许镜像或非等比拉伸。没有同轮廓外壳时以整块
实心外层图配合夹层徽章表达，仍不得逐格拼接。

35 张生成整块资源为：八色 `*-l-tetromino.png`；红/紫/青 `*-z-tetromino.png`；蓝/粉/紫/青/红 `*-plus-pentomino.png`；八色 `*-rectangle-2x3.png`；八色 `*-square-3x3.png`；蓝/粉 `*-horizontal-4.png`；粉色 `pink-t-pentomino.png`。它们由 ImageGen 生成并清理为真透明 RGBA；后续项目方同名正式切图可直接替换。当前关卡只加载实际需要的整块图，离开关卡即释放上一组动态图。
