# Block Out! 轴向色块与异形轮廓约束 v1.59.0

规则编号：`blockout-rules-v1.59.0`。定稿日期：2026-09-26。运行时继续 `revised-2026-09-23-v1.4`。

## 最新用户明确指令及与v1.58的差异

用户明确：“轴向色块不允许出现在异形色块上，请检查所有关卡。”

自本版本起，所有正式关卡（开局、卷帘/升降隐藏批次及生成器队列中的全部色块）必须满足：带 `movementAxis` 的轴向色块，其实际 `shape` 必须是完整矩形；L、T、阶梯、十字及其它缺角/非矩形异形轮廓不得携带轴向限制。矩形横条、竖条、正方形和其它完整矩形仍可作为轴向色块。

本版本只登记并审计该约束，不自动删除轴向机制、不自动替换轮廓或改动正式关卡。发现违规时，须先逐关记录，再按最小必要改图方案重新验证机制数量、可解性、原向素材、隐藏满铺、完整路线和难度证据；未完成修复前不得宣称全关通过或发布。

## 承继合同

除本版新增的轴向色块轮廓约束及其审计/修复边界外，完整承继 `docs/rules/mechanism-rules-v1.58.0.md` 的全部规则、运行语义、难度定义、验证门禁、发布边界、历史证据保留要求及其它关卡安排。v1.58正文和manifest历史条目保持不变。本文件为新增不可变版本，不回写旧文档或旧证书。
