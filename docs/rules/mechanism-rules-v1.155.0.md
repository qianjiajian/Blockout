## 本轮用户目标

重新生成100关荣耀联赛中同质化严重的关卡，增加机制数量与适用数值，满足真实必挪上下限；求解超过10000次仍未通过则修改色块颜色和造型重新求解，直到完整100关正式完成。

- 最终范围为联赛1–100，保持困难、困难、超难、困难、困难循环（80困难、20超难）。新机制解锁不降低难度，仍以主线模板为基础改编。
- 实际机制解锁以正常主线的现行机制目录核对，不以模板来源关号替代。不得提前加入机关或异形块/棋盘；后期不能统一退化为少量冰门模板而遗漏已解锁机制的设计覆盖。
- 首批100仅5种实体形状位置分区，旧数据可作为来源但不能直接当新多样性验收通过。

## 布局与机制要求

- 扩大主线模板来源，实质重排色块形状、位置、通道、出口与机关配合。不能只交换同形块、局部换色、整体镜转、调整一个出口或积分块标签即作为不同布局。
- 除完整对象去重外，必须检查忽略颜色/编号的整块足迹分区、近似占格、出口、机制结构及分批/全量图册。实现采用的相似度阈值、配额和机制目标需公开说明为实施方案，不冒称用户指定。
- 根据已解锁阶段、棋盘容量和事件库存增加机制真实实例及适用计数，保留可解的顺序/空间配合；不得以库存数冒充机关实例、只调大数字或添加空装饰。无计数机制不虚构数值；增加炸弹秒数不能称作增强难度。
- 开局覆盖、隐藏区逐层满铺、独立相邻色块外色不同、出口规则、生成器相邻异色及所有原向整块素材保持。素材验收覆盖实际所有颜色/形状路径，含隐藏和队列，不以形状可匹配代替贴图存在。不能加隔墙或狭长重复小室来凑必挪。

## 同对象必挪与10000上限

- 困难须16≤L≤真实最少必挪≤U≤20；超难须21≤L≤真实最少必挪≤U≤30。必挪为无道具整关通关中非消除、非剥层有效拖动的最少次数，一次持块可以转弯，不能拿总拖数/单格步数/路线绕行冒充。
- 本轮执行口径：每个候选每次上界、下界求解最多10000个完整棋盘状态，达到上限仍未证明即停止并保留UNKNOWN。该计数单位为实施解释，不伪称用户额外指定。记录发现/访问/展开状态数、动作数、时间和终止原因；单体持块可达格与完整棋盘状态分列。
- 超限未通过后必须实际改变颜色和形状，形成新的候选对象再求解；不得原图提高预算、分批续搜或换工具反复累计搜索规避限制。结构不合法、未支持、超时、缺证据均不是PASS。
- 每个最终对象保存来源、改动、全字段对象SHA、工具/规则SHA、fresh合资格下界、完整有限路线、独立实际模型回放；旧对象的证明不能套到新图。

## 积分、正式验收与保持项

- 每关1–3个积分块，仅允许非异形的实心矩形块；不得开局直接挪出，完整路线中位于解开后半段。每块完整消除10分，成功才入榜，失败/退出不保留，使用道具规则与现有结算事务保持。
- 满100关设计/结构/素材/预算/上下界/路线/积分全部通过，再逐关验收正式运行双屏Pointer、自然钟、全库存与实际结算；模型证明和浏览器验证分开记录。完整正式目标不缩成样例或部分批次。
