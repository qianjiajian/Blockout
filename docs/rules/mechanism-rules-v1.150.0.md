# 每日挑战系统 v1.150.0

- Rule ID: `blockout-rules-v1.150.0`
- Runtime profile: `revised-2026-09-27-v1.5`
- Frozen on: 2026-10-04
- 完整承继 v1.149 及全部历史合同。本轮新增独立每日挑战，不改变主线关卡、主线解锁、主线星级或主线奖励。

## 用户确认规则

- 每个机制解锁阶段生成三档每日挑战，每档10个候选关卡；当天每档固定抽取1关。
- 每日挑战关卡由已有主线关卡改编。当前阶段新解锁机制必须出现在该阶段候选池中，其他已经解锁的机制允许组合出现。
- 阶段依据玩家实际已解锁的主线机制计算。当天阶段锁定；当天继续推进主线不会刷新每日挑战，次日按新的解锁阶段生成。
- 每个玩家独立使用自己的随机种子。同一天、同一难度的选中关卡固定，重新进入、重试和重开不重新抽取。
- 只有难度1“难”、难度2“超难”、难度3“超超难”三个等级。难度3要求必挪次数大于30；难度1、2沿用对应主线难度池，不额外假定未确认的数值区间。
- 每日挑战初始次数和最大次数均为3。失败、中途退出、重开均消耗1次；每经过1小时恢复1次，最多恢复到3次；离线经过的时间同样计入恢复。
- 首次成功奖励：难度1金币50、灵感20；难度2金币100、灵感50；难度3金币200、灵感100。重复挑战没有奖励。
- 每日挑战不发放主线基础金币，不记录三星评价，也没有三星条件，只有关卡时间限制。
- 允许使用时间停止、火箭、脉冲，并直接从主线道具库存扣除；失败、退出、重开不返还已使用道具。
- 每日挑战通关、失败和退出都不改变主线进度、当前主线关卡、最高主线关卡、主线解锁、主线星级、主线奖励或主线每日任务。
- 选中难度后直接开始当天固定的随机挑战，不再增加二次选关。

## 阶段选择执行口径

用户对“是否可以选择历史机制阶段”未作出选择。本版本采用当前阶段口径：界面不提供历史阶段选择器，每日挑战只使用当天按实际主线解锁状态确定的阶段；后续如需开放历史阶段，另立规则版本。

## 实现与验收边界

- 核心状态独立保存 `dayKey`、阶段、三档10关候选池、每日抽取结果、次数、小时恢复时间戳、完成与奖励标记。
- 每日挑战运行使用独立 active-run 标记；结算只写每日挑战奖励并清理运行标记。
- 本轮验证每日挑战核心测试、音乐/暂停回归、TypeScript、Web 构建和内部浏览器入口与结算候选检查；不访问真实玩家存档，不打包、上传或发布。
