## 每关先形成新设计合同

1. 绑定来源视频/帧/独立清单和哈希，保留未知项。来源原值不反向改成候选值。
2. 列出冲突字段、来源要求、违反的本游戏规则，以及为何合法位置/承载重排不能消除冲突。
3. 只为冲突字段写新目标及映射：形状转换清单、门保留/移除及原冰数、壳属性撤销对应块；未冲突项继续原合同。
4. 分列三种结果：本游戏硬规则、未冲突来源对齐、获准差异。不能一个“已对齐”布尔值把差异或未知吞掉。
5. 生成器按新目标构造，独立验收再核对源→设计差异和设计→候选实际数据，不只过滤旧校验错误。
6. 静态通过后仍需完整无道具路线、fresh模型回放；真实时间/炸弹、最终正式入口Pointer/Canvas、旧总时限及构建包体分别验证。新数据绑定新SHA，旧路线不直接沿用。
