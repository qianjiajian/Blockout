## 已查看示意的布局建议（非冻结规则）

- 彩色地格示意中，红色空心地格与普通棋盘格一一对齐，连续3格紧邻排列。应位于棋盘底板之上、活动色块之下；保持为同一个固定逻辑格，不浮成色块，不画三角/星凸起，也不在进入时消失。源尺寸略异：76–77px宽、77–78px高，是切图边缘差异，不代表逻辑格大小不同。渲染时对齐相同cell矩形，勿按文件宽度改变棋盘格布局。
- 轴向示意中，每个长条块只叠一个白色双向箭头，位于块可见顶面中部，不随长条长度拉长。示意格约85px，徽标视觉约60–70px，可从0.75–0.82cell长边开始校准；保留原比例，横向为1:1，纵向为61:84。原图已经含阴影，不再画额外背景框。对于异形块，选择实际块内位置，不能让徽标中心落进形状缺口。
- 炸弹计数不在PNG里，保持独立文本，不导入 `炸弹/定时器.png` 综合说明图。

## 去重与打包测量

2026-09-21对本次导入前 `public/assets` 图片审计：PNG字节SHA无重复；PNG及58张WebP/JPEG均无相同宽高候选，因此无可直接复用的整图RGBA等价资产。本目录不是从旧临时图重复拷贝。

原63PNG ancillary元数据总计0B，不能靠删除附加元数据省空间。仅内存测量、未改任何素材：

- `sharp.png({compressionLevel:9, adaptiveFiltering:true, palette:false})`：698,674B，63/63解码RGBA完全一致，只省26,488B。
- `sharp.webp({lossless:true, effort:6})`：533,966B，但0/63严格RGBA一致（透明区RGB被规范化等）；不能宣称字节级RGBA等价，也未采用此结果替换原图。

导入前共同微信总包余量58,162B。直接增加725,162B的PNG，比余量多667,000B；尚未计代码或证据文件。拆分子包不能减少总包，按需加载也不能减少上传总量。先保留Web/隔离场景原图，微信包需要主任务另行审核可复现无损打包及被替代旧临时资源是否可退役。没有为了通过包体门禁删除别的资源或降低画质；本目录存在不表示微信新包已通过。
