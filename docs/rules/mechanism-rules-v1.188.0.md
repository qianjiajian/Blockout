## 三榜与省份

- 页签顺序为周榜、省榜、全国榜。省榜显示已确定的省级地区名称。省份优先通过已配置的IP归属接口自动识别；不可用、超时、失败、非受支持地区均随机分配一个受支持的省级地区，一次确认保存后保持稳定。无手动选择或修改按钮，不要求GPS位置权限。随机回退不冒称真实所在地；接口缺配置应记录真实状态，不硬编码假接口成功。省份来源仅存省级代码及自动/随机来源，不存IP、经纬度或详细地址。迟到结果不得覆盖已经保存的随机地区，未知保存仍重试同一省份候选。
- 三榜仍为本地模拟100人榜（99个对手及真实玩家），不冒称联网真实全国人口排名。全国99个固定身份分配省份；省榜复用其中该省对手并补足本省99人；周榜使用同省人群。相同身份在三榜中的姓名、头像、累计星数与增长轨迹一致，榜单只改变筛选与计分字段。
- 周榜按北京时间每周一00:00切换，只统计本周主线真实最佳星数的净增加。首通得星与重玩补星计入，重复取得已有星不计入，每日挑战/联赛/临时测试不计入。省榜/全国榜继续按有效主线累计星数。全部同分玩家优先，其余对手用稳定身份排序。
- 个人资料“关卡排名”和成功后的主线排名提升动画统一使用全国榜。

## 迁移、时钟、显示与保存

- 旧累计星、关卡进度、资源、个人外观和其它系统保持。旧档缺少获得星的日期，不能重建历史周成绩；本周从新版启用后开始记录，既有累计星不灌入周分。对手沿稳定起始时间计算；本轮规则改变造成的名次重排不伪造为通关提升动画。
- 排行时间单调，时钟回拨不能倒退对手或重置已记周分；跨周、久离线只维护当前周，成功结算候选中的时间/周归属冻结，保存未知重试不得用重试时间改写、重复增星或重新随机地区。
- 一次进入排行榜采用统一时间快照，三标签切换不突然追时跳分。离开重进/真实成功结算刷新；留在周榜跨周需正常切换到新周，不将旧周成绩挂在新周。省份异步处理不阻塞游戏其它页面，不覆盖其它期间保存的新进度。
- 全部新字段深拷贝并严格归一化，保持既有候选保存事务、首次通6解锁及引导、50/100人各自榜单边界、既有奖励与资料外观合同。
- 本轮仅本地Web，真实接口需可用服务配置；无配置随机兜底可正常使用，不冒称真IP识别或真机验证。不访问真实玩家存档，不自动微信打包、上传或发布，不重写旧规则hash或旧证据。
