## 火箭消除表现

- 火箭成功消除色块后，以被消除色块的中心为起点播放短促爆闪、色块碎片散射和轻微棋盘震动。
- 该表现与火箭离场幽灵动画独立，不延迟或改变模型提交；现有成功结算才扣除火箭、失败/重开/离开不扣和完整通关路线保持。
- 减少动效、暂停、后台和转场时遵循现有粒子暂停与清理规则。
