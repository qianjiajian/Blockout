## 用户授权

用户要求：“第7关关卡调整为死局，然后玩家在拖动色块进到达死局时，引导使用火箭消除指定的色块，消除后必须能够完成关卡，不要出现死局；只有完成第7关以后才正常扣除火箭道具，没有通过第7关，无论是否使用火箭，都不扣除火箭数量；每次重新进入第7关，达到死局都要触发引导。”

## 第7关专用死局与引导

- 第7关的授权触发序列是：粉色 `cc-piece-04` 从顶部出口离开；随后将黄色 `cc-piece-03` 拖到 `[0,0]`。此时棋盘没有可用出口，且该状态是本规则唯一的火箭救援触发点。
- 到达该精确无出口状态后，若玩家已解锁火箭且本局仍有可用火箭库存，显示不阻塞操作的手指引导。第一阶段指向真实火箭按钮；玩家点击火箭后，第二阶段指向黄色 `cc-piece-03`。没有火箭库存或未达到精确死局时不显示。
- 玩家用火箭移除 `cc-piece-03` 后，沿已验证路线可以清空第7关；引导立即消失，不再把已移除的色块作为目标。此救援只保证第7关存在可完成路线，不改变普通拖动、出口匹配、星级判定或失败判定。
- 引导状态属于本局运行态。失败、通关、重开、返回主城、离开本局或重新载入时清除；每次重新进入第7关，达到上述死局都重新触发，不使用跨局“已看过”标记。暂停、后台、转场期间不推进引导动画。

## 火箭库存与结算

- 第7关救援使用的火箭采用本局预留：点击火箭和移除目标时不立即减少持久库存，只累计本局实际使用次数；撤销会减少预留次数，不能把库存加到使用前的上限之上。
- 只有第7关成功结算时，才从结算候选存档中扣除本局实际预留次数。第7关失败、重开、返回主城、离开或恢复中断运行时，预留被丢弃，持久火箭数量保持不变。
- 其它关卡和其它道具沿用原有的即时扣除、撤销与结算逻辑；不访问或迁移既有玩家存档中的旧运行态。
