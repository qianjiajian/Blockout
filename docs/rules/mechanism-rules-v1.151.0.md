# 每日挑战每日五次与北京时间零点重置 v1.151.0

- Rule ID: `blockout-rules-v1.151.0`
- Runtime profile: `revised-2026-09-27-v1.5`
- Frozen on: 2026-10-07
- 完整承继 v1.150.0 及历史合同；以下只替换每日挑战次数与日界线，旧锁定文档不改。

## 用户本轮要求

- 取消每日挑战每小时恢复次数的设置。
- 每日固定 5 次挑战次数，每天北京时间 00:00 重置为 5 次，不累计前一天未用次数。
- 在线和离线使用同一北京时间日界线；当天耗尽后等待次日零点，等待若干小时不会增加次数。

## 执行口径

- 用户的“每日背景时间0点”按“每天北京时间0点”执行，固定 UTC+8，不随设备时区改变。
- 每日挑战的日标记、当天关卡抽取/阶段与奖励标记使用同一北京时间日界线，避免次数与每日内容在两个不同时间刷新。
- 保持既有实际扣除流程：每次成功进入挑战预扣1次；失败或退出不再重复扣、不返还，重开新一局再扣1次。此次不改奖励、主线体力、道具消费或关卡内容。
- 跨零点正在进行的关卡保留开局时的关卡与结算归属；回到挑战菜单或开始新一局时应用新日5次，不把旧局奖励算作新日首通。
- 本地时钟回拨不重复发放同一日次数或奖励，沿用最大已观察日期保护。
- 旧版三次/小时恢复存档升级使用一次性标记：保留当天已有抽取、奖励和进度，将剩余次数在旧范围0–3中校验后加2，得到新范围2–5；不虚构旧存档未记录的历史消耗。新版本重读不重复补2，次日统一重置5。旧恢复时间戳不再用于加次数。

## 不变范围与验收

- 三档各10关、当天每档固定1关、玩家独立种子、按实际机制解锁阶段、难度3必挪大于30、每日首通奖励及道具/主线隔离规则保持。
- 每日任务和联赛各自的日历/赛季时间逻辑不随此次变更。
- 检查新用户5次、同日不恢复、北京时间零点及离线跨日重置、回拨保护、旧存档一次迁移、跨日进行中的挑战、UI倒计时与不足提示；不读取真实用户存档，不打微信包、上传或发布。
