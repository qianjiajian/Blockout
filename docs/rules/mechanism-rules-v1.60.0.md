# Block Out! 轴向异形色块修复与重新求解 v1.60.0

规则编号：`blockout-rules-v1.60.0`。定稿日期：2026-09-26。运行时继续 `revised-2026-09-23-v1.4`。

## 最新用户明确指令及与v1.59的差异

用户在审计发现10个“轴向色块位于异形轮廓”后明确：“修改这些有问题的色块，然后重新求解”。本版本授权对审计命中的54、56、63（两块）、89、101、118、135、172、194逐项做最小局部修复，并以修复后的最终 `LEVELS` 重新进行静态审计、完整可解回放和适用的难度核对。

修复策略保持棋盘宽高、可玩格/阻挡/分隔、出口、颜色、卷帘/升降区域与计数、队列、时间/三星、奖励、存档和其它191关不变：

| 关卡 | 修复 |
|---:|---|
|54|移除异形 `s54-13-blue-axis` 的轴向标记；该关没有能沿既有路线保持水平轴向的同色矩形，保留其形状/位置。|
|56|移除异形 `s56-o2` 的轴向标记，将水平轴向约束转移到同色矩形 `s56-o1`。|
|63|移除两个异形轴向块的标记，将水平约束转移到同色矩形 `v146-63-opening-9`；`opening-11` 的既有完整路线同时需要水平和垂直移动，不再强加单轴限制。|
|89|移除隐藏异形 `a89-s12-01` 的轴向标记；同色矩形路线同时需要水平/垂直移动，不迁移单轴限制。|
|101|移除隐藏异形 `r147-101-cover4-9` 的标记，将兼容其既有水平路线的轴向约束转移到同色矩形 `r147-101-opening-5`。|
|118|移除异形黄色L3 `v111-118-b6` 的轴向标记；保持其原向形状、位置、开局覆盖及相邻红色单格不变。|
|135|移除异形 `v190-135-b01` 的轴向标记；同色矩形 `b13` 的完整路线需要先横移再纵移，不迁移单轴限制；隐藏单格 `v190-135-hidden2` 不改。|
|172|移除隐藏异形 `cover172-b8` 的轴向标记；同色矩形 `cover172-b5` 的完整路线同样需要横纵配合，不迁移单轴限制。|
|194|移除 `open0` 的轴向标记；其余形状、位置和蓝色出口保持不变。该关没有同时满足同色、原位置与蓝色顶部门宽的兼容矩形，继续迁移会改变棋盘结构，因此采用最小安全修复。|

除第56、63、101关将约束迁移到兼容矩形块外，其余命中项移除局部不兼容轴向标记；不通过删除渲染分支、旋转/镜像贴图或拼接素材来修复。第118关必须经过实际覆盖与可解检查，第194关必须以无轴约束的最终对象重新回放；两关不因静态通过而冒称旧难度下界仍成立。

## 验收与发布边界

1. 修复层位于既有最终关卡管线末端，旧v1.59文档、审计报告、候选和证书不改写；所有200关最终对象重新检查，违规数必须为0。
2. 9个受影响关逐关执行当前 `PuzzleModel` 的完整无道具求解与独立回放；求解预算耗尽、UNKNOWN、回放失败均记为未完成，不用旧路线或旧标签替代。修复改变色块形状/轴向约束后，原必要腾挪下界与时间/三星证据不自动继承。
3. 静态门禁、隐藏逐层铺满、原向素材、出口/轴向兼容、机制数量与最终LEVELS哈希分别记录。通过后只更新本地正式数据和验证证据，不上传微信、不清理玩家存档、不发布。
