# 14 项正式机制校验报告（2026-09-19）

校验对象是当前运行时 `LEVELS`（Lv1–200）、`PuzzleModel`、求解器语义与 Canvas 表现。机制目录仍为 14 项，首发关卡与实际运行时一致。

## 结论

- 13 项机制的规则、数据边界和代表关卡回放均通过。
- 卷帘的倒计时、碰撞、释放和绘制投影规则通过；Lv21 已按竞品证据修正为 3 个真实覆盖区，Lv103/105/112 已在保留权威矩形的前提下重新装配开局与隐藏批次；四关均通过求解与 PuzzleModel 回放。
- 全 200 关卷帘区域硬审计另发现 28 关历史数据不满足“显示区 = 物理保留区 = 隐藏批次所在区”。这些关不能仅放大贴图：部分关需要同步重排开局块与隐藏批次，部分还需要恢复竞品棋盘 mask 后重新求解。

## 全季卷帘区域审计

强约束：

1. 卷帘矩形的每个格子必须是 playable；
2. 对应隐藏批次的每个形状格必须位于卷帘矩形内；
3. 同一隐藏批次不能自相重叠；
4. 正计数卷帘不能覆盖任何开局可见色块。
