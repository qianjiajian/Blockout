# Block Out! 新机制与关卡生成规则 v1.14.1

规则编号：`blockout-rules-v1.14.1`。定稿日期：2026-09-23。运行时标识：`revised-2026-09-23-v1.4`。

本版本是v1.14.0的文字澄清补丁，运行时仍为`revised-2026-09-23-v1.4`，不声称用户又授权了新玩法。v1.14.0登记后，实现复核发现“legacy开钟规则不改”的概述遗漏了成功使用冻结时启动本局的必要特例，并需说清既有三星耗时的统计口径；本版本在第0节补全，旧v1.14.0及其校验值保留，不能原地改写。

用户已明确的要求仍是：时间道具暂停总时间和炸弹，每次10秒。10秒是用户确认值，不从竞品默认值推导其它授权。其余使用与状态边界属于实现约定。相对v1.13，仅迁移时间道具及必要计时状态，翻门时序、其他机制、空间、地图、奖励与三星门槛保持。旧16份正文、manifest条目、资料和证据保留；先记录本澄清依据，再登记完整正文并冻结。

## 0. v1.14时间冻结：用户要求、实现约定与v1.14.1文字澄清

1. 用户明确要求时间道具暂停关卡总倒计时及炸弹，并确认每次10秒。本版本将原加时道具的玩家效果替换为冻结，不再给总倒计时加30秒；名称为“冻结”，库存键继续为`time`，不新增第四种道具。
2. 以下边界为落实该要求的实现约定，不声称用户逐项另外确认。冻结成功后产生10秒剩余效果，同时通过现有start()启动本局计时流程及原自动装置；即使legacy关尚未首次拖动，也从该次成功使用起消耗冻结余额。这是冻结使用路径的启动特例，普通未用道具的开钟时点保持。有效游玩tick只消耗冻结余额，总倒计时和炸弹秒数在该时段保持不变。跨越冻结到期的tick，仅其超出冻结余额的部分按原计时规则扣时，不追扣被冻结的时长。
3. 冻结覆盖全局主时钟以及已经激活、冻结期间随后激活的炸弹。各profile原有的炸弹可操作/可见性门槛不改；限制解除后仍受剩余冻结保护，效果结束才按原门槛继续计时。不以冻结取消冰、锁、隐藏限制或拆除炸弹。
4. 冻结期间玩家仍可正常移动；离场、剥壳、翻门有效完成回调、冰/卷帘计数、钥匙、固定空间生成器及揭层正常推进。冻结不是暂停整个游戏或停止动画，v1.13的离场完成翻门合同继续适用。
5. 暂停界面及切后台不消耗冻结余额；恢复时不追赶暂停/后台时长。冻结结束后恢复原有计时方式，不重新开启已结束的一局，也不重置任何炸弹初值。
6. 剩余冻结大于0时再次点击不叠加、不续期、不扣道具；失败或已通关不可使用。一次成功使用扣一个既有time库存，失败请求不消费；原180金币单价、上限9及最高关达到Lv4解锁均保持，旅程奖励与存档继续使用原time键。
7. 快照、克隆、撤销及取消必须保存和一致处理冻结剩余状态，不允许陈旧快照、重复事件或取消手势凭空延长已消耗的冻结时长。恢复动作与道具既有使用/退还记录须一致；重开、换关不带入上一局的冻结。不以此迁移自动修复或放宽其它历史撤销规则。
8. 所有关卡的玩家时间道具统一改为冻结；第1–20关保持原legacy空间、计数及普通开钟规则；成功使用冻结时按第2项启动本局，不为改道具升级其关卡profile。第21–200关仅将runtimeProfile从v1.3迁移到`revised-2026-09-23-v1.4`；全部关卡布局、机制配置、奖励、原总时限和实际三星门槛保持，不清存档、不重新设计地图。既有runElapsedSeconds继续按主倒计时实际扣时累计，冻结期间主钟不扣时，因此该累计也不增加；这项说明澄清现有统计方式，不修改星级门槛。
9. GUI显示剩余冻结时间，名称、商店效果、使用反馈及旅程奖励名称均须对应冻结。十语言文案保留既有存档/业务键，不能界面仍称加时30秒而模型已暂停计时。常量`TIME_FREEZE_SECONDS=10`用于实现时长，文案明确10秒。
10. 验证须区分总时间/炸弹冻结、效果内激活炸弹、跨到期tick、正常移动及机关推进、重复点击不消费、失败/通关拒绝、暂停/后台不消耗、历史/取消安全，以及200关仅指定profile迁移。旧v1.13模型/Pointer证据保留，不冒称新冻结道具验收；无道具通关、自然时钟、三星标定和发布仍分别记录。

以下为承继的完整机制与设计合同；遇到时间道具与当前profile范围表述，以本节v1.14变更优先。

## 0.1. 承继v1.13的翻门动画事件合同

1. 用户明确授权的是翻门等待离场动画完成。每次本体移除或成功剥层，仍使全部翻转门各切换一次，包括本次所用门；移动、失败出门和仅播放无效动画均不产生翻转。门色、触发次数及触发对象范围不改。
2. 开始离场时按原规则结算本体移除/剥层、冰门/可见冰块/卷帘减数、钥匙与锁、剥壳拆弹及既有空间投放/揭层；只有翻门切换延后。钥匙仍须本体移除才释放，剥层不释放钥匙；此版本不借竞品差异改其他机制。
3. GUI中，每次有效离场登记一项待完成翻门事件；对应本体离场或外壳剥离动画结束后，由有效完成回调提交模型的实际open切换，并在此时开始门的翻转表现。普通出门以主体完整吸入完成为节点，其后装饰碎屑不延迟翻门；剥壳以该次外壳剥离动画完成为节点。等待期间门的实际通行状态保持原值，不能模型先翻、仅把视觉延后，也不能让动画绕过模型独立改规则。
4. 多次离场分别产生独立事件，每项只能完成一次；不能以“已有待翻转”合并或丢弃第二次事件，也不能因重复回调多翻一次。动画重叠时，各自在自己的有效完成时点结算；同一门最终状态由实际完成次数决定。等待翻门不全局锁住输入，其他合法操作仍按当时真实门状态判断。
5. 暂停及切后台不推进离场完成、不在后台用计时器偷偷翻门；恢复后随仍有效的动画继续并完成其事件。失败、重开、换关、离开本局、撤销或取消导致原动作被作废时，原动画的陈旧回调必须无效；快照恢复、模型替换或重复回调不能重新触发已完成/已作废事件。
6. 最后一件有效离场也保留恰好一次翻门结算，不能因提前标记棋盘已清空漏掉其有效完成事件；真正终止本局或该事件被作废后不得补发。失败与本局撤销的既有状态恢复规则保留，不以此授权修复或重新定义其他撤销行为。
7. 玩家火箭沿用现有一次整块清除事件及其他效果；它触发的一次全门翻转等该次主体收缩/消失动画结束再生效。不改为竞品的单格火箭，不新增道具或改变库存/价格。
8. 无动画的headless模型把离场视为立即完成，保留动作后稳定态求解与独立回放语义；GUI必须显式启用等待动画完成的模式。headless即时完成只是明确的执行模式，不是允许GUI跳过动画事件；只测headless不能证明新动画时序正确。
9. v1.13已对21–200引入离场完成翻门；本版本继续承继并按第0节迁移到runtimeProfile `revised-2026-09-23-v1.4`。1–20仍保留legacy，现有前20关无翻门。关卡几何、块/门/队列/区域配置、奖励、总时限、实际三星目标及用户存档保持；仅时间道具按第0节统一替换，不能将旧空间/翻门profile悄悄解释为新延迟行为。
10. 新模式须分别验证开始离场前后、动画未完成、有效完成、重复完成、并发离场、末次离场、暂停/后台及失败/重开/撤销后的陈旧回调。旧稳定态路线与历史证据保留，但不得冒称已通过v1.13自然时间、Pointer输入或动画验收；变更后的实际文件和运行态须重新绑定证据。
11. 以下完整硬规则承继v1.12。第1节的30关范围仍只约束既有独立原创地图设计授权，不限制已经授权的21–200运行时升级；其中“其他170关不动”指地图与数值等原范围，不阻止profile升级。本节承继M05时点与生命周期，第0节另明确本次时间道具迁移；其它规则不新增或放宽。

2. 这30关独立原创，旧正式地图、旧失败候选、旧轮廓和块数不再约束新设计；不再因旧资料缺帧、旧mask与源尺寸矛盾、旧大块缺图而沿用未完成地图。新设计自行确定合法宽高、轮廓、块数、机制组合、数量及初值，写清原创设计规格，不把自主值冒充已核实竞品值。
3. 此范围不再以旧竞品逐关精确对齐和旧候选证书作为生成前置。参考资料和已有机制主题可以帮助设计，但不得复制旧关布局冒充重做，也不宣称“竞品完全一致”或“全季首次引入已认证”。不以这项授权删除机制实现、改运行时语义或把30关一律降成无机制同模板。

5. 未在清单内的关卡仍保留v1.11的来源/设计授权与历史证据，不因本次重做扩大范围。旧资料未知继续标未知；原创设计不等于补齐来源。
6. 已获准生成正式数据，无需每关再找用户确认。只有新候选空间合法、完整无道具路线及独立回放通过后才写入。未通过不能计完成，不能为了凑齐数放宽硬规则。

## 2. 空间、颜色、开局与形状硬规则

- 使用现有8色。每色最多一个非星实体出口；有对应星块时允许再有一个同色星门，同类同色不得重复。冰冻、翻转属性不增加颜色名额；多个实体口分别计数，不以同ID、多portal拆门绕过。
- 出口通常至多3格。仅同色可通行块在该方向的完整横截面超过3格时，扩大到实际所需宽度；2×2面积4不是4格门理由。宽块不以细柄钻窄门，不拼接门口，不只缩画面而保持大碰撞。
- 所有块的实际足迹必须可玩且同一活动层不重叠。棋盘、出口、机口、卷帘使用同一实际几何；棋盘缺口和分隔不可穿越。不用装饰、假墙、假隐藏掩盖问题。
- 生成器位于真实棋盘边缘，机体不与出口及其他机体重叠。队列固定顺序与固定落点；每件完整足迹合法且包含机口中心相邻格，不远端寻空位、不仅触碰侧口。所有队列块禁冰。
- 卷帘必须有实际矩形覆盖区和真实隐藏块，每个隐藏块完整足迹位于其卷帘中；不同卷帘不重叠，不覆盖无关开局块；隐藏区域无需自身填满。电梯按实际区域占位判定。
- 开局按初始化自动投放/揭层及动画结束后的首个可操作稳定画面计数。该画面每个可玩格由可见块实际足迹或尚未揭开的真实卷帘覆盖；隐藏/队列本体、门、装饰、空地格不能充覆盖。
- 开局不同可见块正交相邻必须异色；不约束玩家移动后。外壳按当前外色计，内外层算同一独立块。
- 异形块按非完整矩形足迹识别，开局与全关分别不超过独立块数的30%，不按面积，不用新增块稀释已有锁定数量；本批原创块数在设计规格中明确。
- 色块整体平移，不旋转、不拆分。使用当前已有完整切图支持的形状及外壳组合，不引入不可见大块或缺图块。原图资源和UI不因本次地图重做改写。
- 不使用非空间staging、旧时间/按动作次数生成器或旧装饰机制凑数量。

## 3. 15项机制：承继v1.13，计时适用v1.14冻结

| ID | 机制 | 规则 |
|---|---|---|
| M01 | 色块生成器 | 固定队列/完整落点；全空即投放，堵塞不扣数、不换位置。投放后下一件条件仍满足则继续检查，不加每次操作最多一块或按时间触发限制。中心相邻格出块，队列禁冰。 |
| M02 | 轴向块 | 只沿指定横/纵轴双向平移，出口方向同样受限，不旋转。 |
| M03 | 钥匙与锁 | 钥匙块本体完全移除，同钥匙组的所有锁减1；剥层不减。锁归零可动。锁3表示需3件匹配组钥匙块移除，不是一个钥匙分值3。钥匙组与块出口颜色独立，各组标识可辨识，不能把不同组画成同色同组。 |
| M04 | 星块与星门 | 星块仅走同色星门；普通块也能走同色星门，星块离场不把星门改普通。有真实对应星块才能普通+同色星门配对。 |
| M05 | 翻转门 | 每次本体移除或成功剥层，在对应离场动画完成后使所有翻转门实际状态各切换一次，包括本次所用门；等待期间保持原open。移动/失败不触发，门色不变。多次事件各自一次，生命周期及headless即时完成见第0.1节。 |
| M06 | 彩色地格 | 当前外层同色才可进入，不自动消除或变色，地格持续存在。整关禁止外壳，含隐藏与队列。 |
| M07 | 炸弹 | 冰/锁/隐藏/队列等限制解除、块可操作后才计时；开局可操作炸弹随统一计时立即开始，不等第一次拖动。暂停不计；时间道具冻结期间总倒计时和炸弹按第0节停计，后续激活炸弹同样受剩余冻结保护。0前未解除则失败。炸弹绑定外壳，剥壳解除且内芯不继承；单层块随本体移除解除。 |
| M08 | 卷帘 | 每次本体移除或剥层减1，归零揭开整组；移动不减。显示与实际阻挡同区，须有外部推进路径，不形成互等死锁。 |
| M09 | 电梯 | 固定区域全部腾空后揭下层，不是搬运平台；任意当前可见块部分占区也阻挡。揭层前检查全部新足迹，整体释放，不穿插重叠。 |
| M10 | 普通出口 | 匹配当前外层色，实际前沿贴口且完整横截面包含于单个门内。凹边、星/冰/翻门同样遵循，不允许宽块穿窄门。 |
| M11 | 异形块 | 实际足迹碰撞，整体平移；双阶段各≤30%。 |
| M12 | 异形棋盘 | v1.12清单30关可新定尺寸/轮廓，至少左右或上下镜面对称、单连通、无内部孤立阻挡。块不越缺口/分隔缝。 |
| M13 | 冰冻出口 | 冰>0不可用；每次本体移除或剥层减1。 |
| M14 | 数字冰块 | 冰>0不可移动/消除。其他块本体移除或剥层时可见冰块减1。允许隐藏冰，显示前不减；揭开当次不追扣，从下一次有效清除开始。队列禁冰。 |
| M15 | 外壳 | 最多外壳+本体两层且异色。剥壳保留形状/位置，露内色；剥壳是一清除事件，不是本体移除。 |

## 4. 结算与一致性

1. 每次整块或剥层只计一次清除：开始离场按原时点使冰门/可见冰块/卷帘减数，登记一次全体翻门事件并在对应动画结束时实际切换；不因露内芯或完成回调再扣一次其他计数。钥匙只按本体移除结算。headless无动画模式即时完成该翻门事件。
2. 先按本次事件前可见性扣冰，再揭卷帘/电梯；新露冰不追扣。炸弹解除最后限制当帧不追扣以前时间，未选中也会计时。
3. 投放/揭层确定性串行，完整足迹无碰撞，必须终止。自动投放的已发生事件、拖动取消与撤销保持一致，不丢块、不复制，不回拨墙钟。
4. 电梯不只检查原成员ID是否消失；任意外来块压区也要等待。隐藏批次整体释放，不产生跨层同时占格。
5. 结束、失败、暂停后不得继续投放、重复清除/翻转或计数穿零；仍有效的末次离场及暂停后恢复按第0.1节处理，失效回调不补发。快照、克隆、撤销及独立回放的冰/门/队列/炸弹、冻结剩余与待完成事件状态一致；旧回调不得越过恢复后的事件有效性检查。
