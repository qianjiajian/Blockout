# 正式玩法 HUD

本目录最初来自项目方 `切图2/游戏界面/`，并按 `界面UI+空星/游戏界面/` 的最新示意与切图更新。11 张 PNG 均以源文件原始尺寸和字节进入运行目录。运行时以 720×1584 示意图坐标合成，再随完整画板统一等比适配屏幕；禁止对单张图片独立 fit、拉伸、缩放或重新编码。

| 文件 | 原始尺寸 | 用途 |
|---|---:|---|
| `back-button.png` | 88×88 | 左上操作按钮 |
| `pause-button.png` | 88×88 | 右上暂停按钮 |
| `level-pill.png` | 213×88 | 动态关卡号底板 |
| `timer-icon.png` | 30×35 | 倒计时图标 |
| `timer-panel.png` | 152×54 | 动态倒计时底板 |
| `booster-base.png` | 149×149 | 三种道具共用底座 |
| `booster-count-badge.png` | 45×47 | 动态库存数字底板 |
| `booster-plus.png` | 28×28 | 库存为零时的补充标记 |
| `booster-time.png` | 99×104 | 加时道具 |
| `booster-rocket.png` | 90×102 | 火箭道具 |
| `booster-pulse.png` | 94×93 | 脉冲道具 |

最新排版基准只读 `art-source/references/gameplay-v1/screen-reference-2026-09-15-annotated.png`；红色标注仅用于说明字号，不进入运行包。旧版完整界面仍保留为 `screen-reference.png`，用于资源包未覆盖的金币栏等区域。

720×1584逻辑画板的动态文字规格为：金币29px，锚点 `(146, 107)`、最大宽98px；关卡标题为大写 `LEVEL n`、31px，锚点 `(361.5, 202)`；倒计时为 `mm:ss`、33px，锚点 `(371, 288)`；三个道具库存均为32px，锚点分别为 `(200.5, 1434)`、`(410.5, 1434)`、`(624.5, 1434)`。所有锚点均已按 Canvas `middle` 基线对示意图可见字形校准。
