## 用户授权

用户要求“开始制作功能解锁的引导”。沿用明确门槛：主线通关6后排行、8后商店、11后旅程、15后每日挑战、20后荣耀联赛；每日任务与成就在通5开放但不需要引导。

## 实现约定

- 只对真实主线进度首次跨过门槛产生引导，待展示队列与通关候选同次保存。通关保存失败或未知不提前弹出，不用每日/联赛/临时测试进度触发。
- 回到主界面后依次处理金币奖励、既有收藏与新场景提示，再播放功能解锁卡片；不可叠加或打断关卡/结算/页面切换。联赛两页说明保留为真正进入联赛之后的介绍。
- 使用既有界面图标和按钮美术：图标弹出、锁淡出及光晕庆祝；点击“去看看”后高亮真实入口、显示手指和一句说明，点击该入口进入功能。入口阶段只导向该页面，不自动购买、领奖、花费挑战次数或开启关卡。“开始”按钮不新增轻跳。
- 可以选择“稍后”结束本次引导。进入或稍后确认均持久记已处理，不重复播放；未完成即退出应用则保留待展示队列。未知保存重试原候选，确认后才放行，不能覆盖别的交易或重复发奖。
- 旧存档没有本引导账本时，把升级前已开放的功能视作已处理，不集中补弹；升级后新达标功能正常引导。存档规范化不改已保存金币、物品、任务/成就、联赛与关卡数据。
- 前后台暂停动画计时，减少动态效果设置保留静态说明与明确点击，使用微信可用计时及数据复制方式，不依赖新增浏览器全局API。
- 隔离存档真实Pointer双屏验收、相关保存与队列测试后更新本地Web；不访问真实玩家存档，不重打微信包、不上传发布。
