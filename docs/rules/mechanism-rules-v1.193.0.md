## 用户要求及执行顺序

用户明确：“请按照机制解锁顺序来制作。”

后续按现有十阶段的解锁顺序推进：

1. 基础合并阶段：普通出口、异形色块、冰冻出口、异形棋盘、数字冰块、卷帘门。
2. 外壳块（主线第15关）。
3. 色块生成器（第35关）。
4. 轴向块（第50关）。
5. 钥匙与锁（第59关）。
6. 升降台（第65关）。
7. 星标块与星门（第100关）。
8. 炸弹（第120关）。
9. 翻转门（第150关）。
10. 彩色地格（第200关）。

- 每阶段仍为难、超难、超超难各10关，共30关，总目标300关。执行上先补齐最早尚未完成的阶段，再推进下一阶段；不因后期现成对象容易接入而跳过前期缺口。
- 已正式验收接入的关卡及历史证据保留，不撤销、不重复制作或重复计数。未完成的后期制作停止新求解和新接入；已经运行的单次求解允许正常结束并保存原始记录，避免丢失历史。
- 优先复核本阶段已有有效对象；达标一关就接入一关，不等待整阶段30关或全300关齐备。尚缺的对象继续真实换形换色、有限求解和完整验收。

## 保持项及待明确的运行问题

- 独立布局、主线棋盘基准、近似布局检查、机制增强与真实参与、满铺/隐藏层/全库存/原向素材不变。
- 难16至20、超难21至30、超超难下界至少31且有有限完整上界；每次上下界最多10000完整棋盘状态，失败后实际换形换色，不能重复原图续搜。双屏真实Pointer、自然计时和正式查询/结算验收保持。
- 本次制作顺序不等于改变每日挑战开放关号。当前通关15才开放每日挑战，而此时阶段函数已进入外壳，基础池正常新日抽取仍有待确认的规则冲突。已询问保持通15并允许基础池参与后续抽取，或提前通5开放；未回答前不得当作用户已选择。
- 该运行问题不妨碍基础关的制作、同对象数学和静态复核；不能以强行注入基础阶段的测试冒称自然入场已通过，也不再因此绕过基础去制作后期阶段。
- 每日5次、北京时间零点、同日对象和次数/成功/领奖归属、三档奖励、道具库存与扣除、主线及其它系统合同保持。未满足全部300关前不称目标完成，不访问真实玩家存档，不自动微信打包、上传或发布。
