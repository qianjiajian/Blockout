# 正式棋盘边框 V1

本目录来自项目方 `切图2/游戏界面/边框`，运行版位于
`public/assets/art/gameplay/board/formal-border-v1/`。除本说明与
`reference.png` 外，22 张 PNG 均由 `pnpm art:optimize` 逐字节复制；禁止裁切源文件、重采样、压缩或分别改变宽高。

## 尺寸与用途

| 文件 | 原始尺寸 | 用途 |
|---|---:|---|
| `neutral-rail-1-cell.png` | 95×58 | 普通一格直边 |
| `neutral-rail-2-cell.png` | 190×58 | 普通两格直边 |
| `neutral-rail-corner-adjacent.png` | 130×58 | 内凹转角相邻接角段；源图右端朝向内角 |
| `neutral-corner-inner.png` | 60×62 | 内凹角；0° 对应缺失的右上象限 |
| `neutral-corner-outer.png` | 57×59 | 外凸角；0° 对应可玩格位于右上象限 |
| `direction-arrow.png` | 33×26 | 出口白箭头；0° 朝上 |
| `exit-*-1-cell.png` | 95×58 | 八色一格出口条 |
| `exit-*-2-cell.png` | 190/191×58 | 历史两格出口条，仅归档，不参与运行时绘制 |
| `reference.png` | 720×1584 | 项目方拼接示意，仅供核对，不进入运行包 |

颜色映射：1=orange、2=pink、3=red、4=yellow、5=cyan、6=green、7=blue、8=purple。

## 运行时拼接契约

- 以 95px 为一个棋盘格，在棋盘局部坐标中只应用一次 X/Y 相同的设备适配缩放。中性边框和角件按自然宽高绘制；彩色出口是一项明确例外，只沿长度方向拉伸到目标格数。
- 中性直边优先以两格图拼接，奇数余量使用一格图；接角段的源图右端始终朝向内凹角。
- 彩色出口统一只使用对应颜色的 `exit-*-1-cell.png`：每个出口仅绘制 1 张，一格保持95×58，两格横向拉伸到190×58，三格横向拉伸到285×58。出口条整体旋转到四条边，箭头保持33×26自然尺寸、独立居中并同步旋转；禁止重复平铺，也禁止调用或裁切历史两格出口图。
- 出口占用的跨度必须从中性直边中扣除；固定绘制顺序为“中性直边 → 出口 → 接角段 → 内/外角”，让出口真实替换边框并由角片封口。
- 两个凹角之间只有 1/2/3 格时不再垫普通直条。130px 接角图保持整图，通过确定中线裁显；一格双凹的两张 60px 内角也在中线各占一半。
- 内角、外角整块放在对应的轮廓外/缺失象限，不以网格顶点为中心拉伸。

替换时请保持文件名、上述像素尺寸和 RGBA 透明通道；替换后依次运行 `pnpm art:optimize`、`pnpm art:verify` 与棋盘边框视觉测试。
