# 每日挑战450关重新制作与同对象必挪验收 v1.153.0

- Rule ID: `blockout-rules-v1.153.0`
- Runtime profile: `revised-2026-09-27-v1.5`
- Frozen on: 2026-10-07
- 完整承继v1.152及历史合同。本版只登记每日挑战450关重求解、重制和正式接入授权，不修改主线、联赛、经济、UI或玩家存档。

## 用户授权与范围

用户建立活动目标：重新求解450个每日挑战关卡，检查难、超难、超超难的上下限必挪次数；不达标则调整后再次求解，无法求解时通过调整色块形状和颜色改变布局，最终生成450个正式每日挑战关卡。

- 范围固定为现有15个机制阶段、每阶段3个难度、每个难度10个独立布局，共450槽。不能把部分完成或少量样例称为全部完成。
- 按已有主线棋盘和布局为基准改编，允许必要的色块形状、颜色及位置重排，并记录来源与差异。正常棋盘的尺寸与可玩轮廓保留；不能恢复已被用户否定的狭长隔离小室塔，也不能通过添隔墙、重复小组件或只整体镜转/全局换色来充当独立布局。
- 实际关卡必须包含本阶段最新机制，且不得包含尚未解锁机制；可以组合已解锁机制。来源主线关号不等于机制解锁条件，改编对象按实际机制核验。

## 真实必挪与证明

- 必挪指无道具完整通关所需非消除、非剥层有效拖动的最少次数；连续持有同一块可转弯，不能按单格移动、直线段数、总拖数、绕路、评分目标或机关实例数计为必挪。
- 难度1、2依既定主线对应难度验收，当前执行区间分别为难16–20、超难21–30。难度3继续要求大于30，即下界至少31，并提供完整有限通关路线；用户尚未指定难度3上限，不自行增加上限要求。
- 每个实际运行布局必须有同对象fresh下界L与完整通关上界U：难要求16≤L≤U≤20，超难21≤L≤U≤30；超超难L≥31且U有限。证明必须覆盖全部合法连续拖动，或使用经过论证且成本不增的动作超集放宽。
- 求解超时、状态预算耗尽、未支持机制、证据丢失或哈希不一致均保持UNKNOWN/未验收；不得视为下界通过。不能靠向路线插入无用拖动满足下界。
- 为每槽保存完整候选对象、来源和变更记录、规则/工具/对象哈希、完整路线与fresh回放、下界方法/适用范围/结果、布局独立性检查。运行、生成、验证必须绑定同一个对象；旧PASS、字符串标签及过期证书不能用于新图。
- 对同一失败候选采用有限搜索预算；持续未证实时改变形状、颜色或布局，保留失败记录，再重新求解。旧证据不得原地改为通过。

## 保持范围与交付口径

- 主线200活动边界、已登记其他正式关卡、完整联赛100关及历史证据保持。每日5次、北京时间零点刷新、当天固定抽取、成功不可重挑战、奖励和主线道具库存规则保持。
- 通过模型验证不等于已做真实浏览器输入/自然计时；验证报告须分别记录。所有450槽正式同对象数据完成前，不把全目标标为完成。
- 实际进度见WORKSTATE；不读取或改写真实玩家存档，不打微信包、上传或发布。
