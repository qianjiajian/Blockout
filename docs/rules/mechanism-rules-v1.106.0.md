## 用户指令与执行差异

用户在本171–180任务明确：“继续，当求解遇到下限或者上限一直不满足条件时，不要一直求解下去，请通过更换色块颜色、色块种类等方式重新生成关卡”。继续以正式关卡完成为目标。每个候选记录指纹、有限求解预算和真实结果；反复不能满足上下界、持续UNKNOWN或没有完整路线时，更换色块颜色、合法形状及必要排布，重新生成并验证，不无限增加同一失败候选的搜索预算。

本批允许为可解性和难度设计调整已知来源色块颜色、形状，不仅限于容量冲突；来源原值与原创设计差异逐项分列，不将新配置冒称竞品精确事实。颜色或形状调整仍维护外壳、星、钥匙、轴向等机制绑定和真实库存。具体单轮预算由实施选定并记录，不冒称用户指定数值。
