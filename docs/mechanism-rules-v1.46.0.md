2. 以下边界为落实该要求的实现约定，不声称用户逐项另外确认。冻结成功后产生10秒剩余效果，同时通过现有start()启动本局计时流程及原自动装置；即使legacy关尚未首次拖动，也从该次成功使用起消耗冻结余额。这是冻结使用路径的启动特例，普通未用道具的开钟时点保持。有效游玩tick只消耗冻结余额，总倒计时和炸弹秒数在该时段保持不变。跨越冻结到期的tick，仅其超出冻结余额的部分按原计时规则扣时，不追扣被冻结的时长。
3. 冻结覆盖全局主时钟以及已经激活、冻结期间随后激活的炸弹。各profile原有的炸弹可操作/可见性门槛不改；限制解除后仍受剩余冻结保护，效果结束才按原门槛继续计时。不以冻结取消冰、锁、隐藏限制或拆除炸弹。
4. 冻结期间玩家仍可正常移动；离场、剥壳、翻门有效完成回调、冰/卷帘计数、钥匙、固定空间生成器及揭层正常推进。冻结不是暂停整个游戏或停止动画，v1.13的离场完成翻门合同继续适用。
5. 暂停界面及切后台不消耗冻结余额；恢复时不追赶暂停/后台时长。冻结结束后恢复原有计时方式，不重新开启已结束的一局，也不重置任何炸弹初值。
6. 剩余冻结大于0时再次点击不叠加、不续期、不扣道具；失败或已通关不可使用。一次成功使用扣一个既有time库存，失败请求不消费；原180金币单价、上限9及最高关达到Lv4解锁均保持，旅程奖励与存档继续使用原time键。

## 0.1. 承继v1.13的翻门动画事件合同

1. 用户明确授权的是翻门等待离场动画完成。每次本体移除或成功剥层，仍使全部翻转门各切换一次，包括本次所用门；移动、失败出门和仅播放无效动画均不产生翻转。门色、触发次数及触发对象范围不改。
2. 开始离场时按原规则结算本体移除/剥层、冰门/可见冰块/卷帘减数、钥匙与锁、剥壳拆弹及既有空间投放/揭层；只有翻门切换延后。钥匙仍须本体移除才释放，剥层不释放钥匙；此版本不借竞品差异改其他机制。
3. GUI中，每次有效离场登记一项待完成翻门事件；对应本体离场或外壳剥离动画结束后，由有效完成回调提交模型的实际open切换，并在此时开始门的翻转表现。普通出门以主体完整吸入完成为节点，其后装饰碎屑不延迟翻门；剥壳以该次外壳剥离动画完成为节点。等待期间门的实际通行状态保持原值，不能模型先翻、仅把视觉延后，也不能让动画绕过模型独立改规则。
4. 多次离场分别产生独立事件，每项只能完成一次；不能以“已有待翻转”合并或丢弃第二次事件，也不能因重复回调多翻一次。动画重叠时，各自在自己的有效完成时点结算；同一门最终状态由实际完成次数决定。等待翻门不全局锁住输入，其他合法操作仍按当时真实门状态判断。
5. 暂停及切后台不推进离场完成、不在后台用计时器偷偷翻门；恢复后随仍有效的动画继续并完成其事件。失败、重开、换关、离开本局、撤销或取消导致原动作被作废时，原动画的陈旧回调必须无效；快照恢复、模型替换或重复回调不能重新触发已完成/已作废事件。
6. 最后一件有效离场也保留恰好一次翻门结算，不能因提前标记棋盘已清空漏掉其有效完成事件；真正终止本局或该事件被作废后不得补发。失败与本局撤销的既有状态恢复规则保留，不以此授权修复或重新定义其他撤销行为。
7. 玩家火箭沿用现有一次整块清除事件及其他效果；它触发的一次全门翻转等该次主体收缩/消失动画结束再生效。不改为竞品的单格火箭，不新增道具或改变库存/价格。
8. 无动画的headless模型把离场视为立即完成，保留动作后稳定态求解与独立回放语义；GUI必须显式启用等待动画完成的模式。headless即时完成只是明确的执行模式，不是允许GUI跳过动画事件；只测headless不能证明新动画时序正确。

10. 新模式须分别验证开始离场前后、动画未完成、有效完成、重复完成、并发离场、末次离场、暂停/后台及失败/重开/撤销后的陈旧回调。旧稳定态路线与历史证据保留，但不得冒称已通过v1.13自然时间、Pointer输入或动画验收；变更后的实际文件和运行态须重新绑定证据。

## 2. 空间、颜色、开局与形状硬规则

- 使用现有8色。每色最多一个非星实体出口；有对应星块时允许再有一个同色星门，同类同色不得重复。冰冻、翻转属性不增加颜色名额；多个实体口分别计数，不以同ID、多portal拆门绕过。
- 出口通常至多3格。仅同色可通行块在该方向的完整横截面超过3格时，扩大到实际所需宽度；2×2面积4不是4格门理由。宽块不以细柄钻窄门，不拼接门口，不只缩画面而保持大碰撞。
- 所有块的实际足迹必须可玩且同一活动层不重叠。棋盘、出口、机口、卷帘使用同一实际几何；棋盘缺口和分隔不可穿越。不用装饰、假墙、假隐藏掩盖问题。
- 生成器位于真实棋盘边缘，机体不与出口及其他机体重叠。队列固定顺序与固定落点；每件完整足迹合法且包含机口中心相邻格，不远端寻空位、不仅触碰侧口。所有队列块禁冰；同一生成器相邻队列块出块外层色必须不同（v1.29新增）。
- 卷帘必须有实际矩形覆盖区和真实隐藏块，每个隐藏块完整足迹位于其卷帘中；不同卷帘不重叠，不覆盖无关开局块；隐藏区域及升降台每个隐藏层均须由其真实色块足迹完整铺满，逐层校验，不以遮盖或其他层充数（v1.22取代旧未满铺豁免）。电梯仍按实际区域占位判定。
- 开局按初始化自动投放/揭层及动画结束后的首个可操作稳定画面计数。该画面每个可玩格由可见块实际足迹或尚未揭开的真实卷帘覆盖；隐藏/队列本体、门、装饰、空地格不能充覆盖。
- 开局不同可见块正交相邻必须异色；不约束玩家移动后。外壳按当前外色计，内外层算同一独立块。
- 异形块按非完整矩形足迹识别，开局与全关分别不超过独立块数的30%，不按面积，不用新增块稀释已有锁定数量；本批原创块数在设计规格中明确。
- 色块整体平移，不旋转、不拆分。使用当前已有完整切图支持的形状及外壳组合，不引入不可见大块或缺图块。原图资源和UI不因本次地图重做改写。
- 不使用非空间staging、旧时间/按动作次数生成器或旧装饰机制凑数量。

## 4. 结算与一致性

1. 每次整块或剥层只计一次清除：开始离场按原时点使冰门/可见冰块/卷帘减数，登记一次全体翻门事件并在对应动画结束时实际切换；不因露内芯或完成回调再扣一次其他计数。钥匙只按本体移除结算。headless无动画模式即时完成该翻门事件。
2. 先按本次事件前可见性扣冰，再揭卷帘/电梯；新露冰不追扣。炸弹解除最后限制当帧不追扣以前时间，未选中也会计时。
3. 投放/揭层确定性串行，完整足迹无碰撞，必须终止。自动投放的已发生事件、拖动取消与撤销保持一致，不丢块、不复制，不回拨墙钟。
4. 电梯不只检查原成员ID是否消失；任意外来块压区也要等待。隐藏批次整体释放，不产生跨层同时占格。
5. 结束、失败、暂停后不得继续投放、重复清除/翻转或计数穿零；仍有效的末次离场及暂停后恢复按第0.1节处理，失效回调不补发。快照、克隆、撤销及独立回放的冰/门/队列/炸弹、冻结剩余与待完成事件状态一致；旧回调不得越过恢复后的事件有效性检查。
6. 视觉动画不独立扣数或改open；GUI有效离场完成回调提交模型翻门事件，视觉表现同一模型结果。旧运行兼容路径保留但不作为新数据机制；本次21–200显式使用runtimeProfile v1.4（`revised-2026-09-23-v1.4`），承继v1.13动画时序并实现时间冻结；不能只换标签而未实现对应行为。
