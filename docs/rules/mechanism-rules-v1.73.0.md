## 用户指令与差异

用户明确：“继续生成141-150关正式关卡，当求解器找不到候选时不要无上限的求解，请改变色块颜色或者色块种类直到满足关卡条件”。本批以完成正式关卡为目标；每份候选记录有限求解预算和真实结果，未找到合格解就改变色块颜色、种类及为换形所需的排布，再作新鲜求解。允许为求解与难度设计调整已知来源的色块颜色/形状，不再只限容量冲突适配；原始来源与设计差异分开保留，不冒称精确复刻。

## 保留合同

本授权只针对141–150。保留v1.45基线棋盘几何、关号/名字、原时限、实际三星目标和历史reward；保留来源中已知机关种类、数量、初值及真实库存，已获授权的硬规则冲突最小适配仍须记录。不得因工具不支持或搜不到路线而删除机关、隐藏库存或降低难度。未知的机关来源事实不得冒充确证。

所有新块必须有原朝向完整素材；开局及每层真实隐藏区域满铺、开局相邻异色、生成器队列相邻异色/禁冰、轴向完整矩形、出口容量与颜色唯一、异形比例和解锁顺序保持。换色换形不改变运行时移动/出口/计时语义。

本批顺延档位为141简单、142普通、143困难、144简单、145普通、146超难、147简单、148普通、149普通、150简单翻转门首教。仍须5–10/11–15/16–20/21–30内的有效新鲜下界与完整路线，机制/多格决策、最终LEVELS双屏真实Pointer与自然时钟验收。UNKNOWN、超时、仅空间可解和人为绕路均不是难度通过。
