## 运行时契约

- 以 95px 为一个棋盘格，仅使用棋盘的统一等比缩放；横、竖方向直接选择
  对应方向素材，不从另一方向重采样生成。
- 1/2/3 格对象直接选择同长度整图；超过三格时只允许以 3/2/1 格整图组合，
  不缩放到其他长度。
- 冰冻出口使用与出口长度一致的整条素材；`frozen` 数值只决定显示计数，不决定图片长度。
- 本组只用于冰冻出口。冰冻色块统一逐格使用
  `formal-gameplay-v1/ice-cell.png`（来稿 `冰块1.png`，96×104）：水平方向
  居中，图片底沿对齐 95px 名义格底沿，9px 立体厚度向上延伸，不做居中 fit
  或包围盒拉伸。
