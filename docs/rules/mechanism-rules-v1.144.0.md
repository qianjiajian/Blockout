## 图标显示

- 时间停止、火箭、脉冲三种道具在主游戏栏和商店中始终以正常不透明度绘制。
- 未解锁状态继续显示锁图标和解锁关卡；库存为0时继续显示补充提示或数量0。上述状态提示不再通过把道具图标变暗来表达。
- 道具仍受既有 `boosterUnlocked`、库存数量和 `useBooster` 判定限制；未解锁或库存为0时不可使用，不能因图标变亮而改变玩法。
