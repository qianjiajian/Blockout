## v1.6预览原创重配授权（优先于下文来源数量强一致要求）

1. **仅预览、仅有依据的冲突或缺项。** Lv21–200中，来源存在数量/空间/可解组合冲突或资料不完整的关卡，允许为产出完整可解预览原创重配。先尽可能保留已知可满足的宽高、开局/全关数量与机制种类/数量/关键值；不得因为批量方便一律删除机制或重置所有关卡。单次搜索超时不证明来源必定无解。
2. **源事实与设计分离。** 不改原truth或把runtime补数冒充竞品。每个被调整或未知字段记录来源值（未知为null）、预览设计值、调整原因及依据；页面逐关显示差异。资料缺失关可提交明确标为原创假设的预览，不宣称已与竞品核实一致。
3. **颜色/出口冲突。** 来源实体非星门超过8色唯一容量等确切冲突允许在本轮预览重配出口及与之耦合的布局，明确列出原数量、设计数量和保留/调整的冰数、星属性。不是扩色或放宽同色门配额，也不是把Lv26历史特例暗中扩展成正式关卡许可。
4. **仍须满足的空间与运行规则。** 开局满铺、原创左右或上下对称、连通无内部孤岛墙、真实卷帘覆盖与隐藏足迹一致、同色块开局不相邻、异形块开局/全关分别不超过30%、唯一出口颜色及星门配对、门宽、生成器边缘中心口/固定队列落点/队列禁冰、地格与外壳互斥，以及全部15项机制触发、计数、解锁和计时语义继续执行。已知竞品宽高应保持；宽高缺证据时可采用明确标为假设的设计宽高。未知首次引入不能写为已验证，不以重配许可擅自把已知新机制提前到更早关。
5. **完整可解是交图门槛。** 每关保存无道具完成见证，并用独立新PuzzleModel回放；含时间机制须验证真实计时约束。没有完成见证的候选列为未完成，不混入可解通过数。不考核10/15/20下界，不伪造下界或时间三星证书。
6. **后续仍待用户验收。** 当前只生成隔离候选、图片和差异清单，不替换正式LEVELS、Lv1–20、存档、已批准旧图或现有UI/素材。本预览重配不永久废除正式来源合同；正式接入前由用户核对差异并另行批准。本次授权已取得，不再以同一来源冲突重复索取这项许可。

## 本轮可解预览阶段合同（优先于下文正式验收顺序）

1. **范围**：在隔离候选与预览产物内制作Lv21–200，不覆盖正式LEVELS、Lv1–20、用户存档、已批准图片或原始来源。可先交付已完成子批次，但必须准确列出已完成与未完成关数；未通过不能填成全量通过。
2. **不再考核必要腾挪**：本轮不要求普通10、困难15、超难20，不运行下界证明来决定是否出图，也不为凑次数增加难度。有少腾挪通关路线并不导致预览被拒收。下文保留的正式难度合同尚未被永久废除，难度下界、时间/三星标定和正式发布均标为未验证／不适用于本轮预览。
3. **“不是死局”的验证口径**：必须有从首个可操作稳定状态到整关完成的无道具合法路线，并用新的PuzzleModel实例独立回放，覆盖后续卷帘揭开、出货、电梯和机制计数。只有开局能动、旧规则证书、有限搜索没有报错都不构成通过。未求得路线、预算耗尽或工具不支持须如实标注，不宣称可解。
4. **时间依赖不得伪造**：含炸弹等时间约束的候选不能通过删除机制、停止时钟或仅验证空间路线宣称可通关；须附满足真实机制时间的见证。关卡总时限与三星目标可暂不标定，但若使用临时预览时限须明确标注，不能当作正式参数。
5. **其他已确认规则继续保留**：包括原创对称无内部孤岛墙、满铺、真实覆盖、出口配额、相邻异色、异形块比例和运行机制。来源数量/缺项按上文v1.6已明确批准的有限重配执行，并逐关披露；其余要求不自行放宽。
6. **产物诚实绑定**：预览绑定候选哈希、规则版本、来源、求解路线、独立回放及图片数据。旧图或旧关卡可以作参考，但不能仅改标签当作新规则合格候选。规则/来源未核实和可解性未知分别列出，不用“已预览”代替“已通过”。
7. **后续**：用户看图核对后，再决定局部调整、难度优化、时间三星和正式接入。预览认可不等于正式替换授权。

本次只改变生成/验收阶段合同，不改变15项机制运行时语义，runtime仍为`revised-2026-09-21-v1.2`。新产物须另行绑定规则文档v1.6.0；v1.4.0及以前版本的正文和manifest条目全部保留。以下规则中的难度和完整验收要求适用于后续正式阶段，本轮预览按本节例外执行。

以下v1.2已确认授权继续生效：

- 出口同色例外：有对应星块时，只允许“一扇普通门＋一扇同色星门”。同色两扇普通门、同色两扇星门仍禁止。冰冻、翻转是出口的附加属性，不产生额外同色名额。对应星块可在开局、真实隐藏层或合法队列中，其外层/内层需要该星门颜色；不得新增假星块、空星门或多portal来绕过重复颜色检查。
- 第26关特例：不使用竞品的11个实体出口，也不扩展8色色板。用户允许保留3个冰冻出口及初值5、9、14，重新配置普通出口数量，由生成和验证确定最终数量。本关没有来源星块/星门，不得为突破颜色限制自行新增星机制；因此总实体出口最多8，普通出口为1–5。其他关不因此获得删门或重配机制数量的授权，第26关其他机制数量/数值、宽高、开局/全关块数要求不变。
- 来源事实与设计特例分开记录：竞品Lv26仍为8普通+3冰门，不能把来源数据改成候选出口数；候选合同注明本版本批准的普通出口重配特例。原始事实错误的证据修订也不等于修改竞品或正式关卡。

“普通门”在同色配额中指非星标出口（包括非星标的冰冻/翻转出口）。单个逻辑门若有多个实体口，每个实体口分别占用配额。星块仍只能通过同色星门，普通块仍可通过同色星门。

这两条变更不自动迁移旧关卡、不批准尚未验证的候选，也不构成放宽10/15/20必要腾挪下界的授权。

## 机制首次引入与关内出现阶段

1. **首次引入关卡必须一致。** 竞品在第N关首次引入的机制，本游戏也在第N关首次引入，不提前到更早关，也不延后到更晚关。逐关机制种类、数量和关键数值仍按核定来源合同对齐，首次引入一致不能替代逐关核对。
2. **同关内允许放在开局。** 竞品在卷帘揭开、电梯揭层等后续阶段才显示的机制，候选允许在同一关的首个可操作稳定画面中出现；不要求照搬关内第几秒、玩家第几次拖动或揭露先后。允许提前显示不是强制全部移到开局，仍可采用合法隐藏阶段。
3. **阶段重排不能改变数量合同。** 允许重新分配开局与真实隐藏批次中的机制承载块，不把竞品各隐藏批次的冰块/外壳分布原样复制作为额外硬限制来否定本次许可。开局和全关块数、机制总数量/关键数值、卷帘或电梯本身的数量/参数及已核定隐藏批量仍须满足；可通过重新布局、交换合适承载块的阶段保持这些要求，不能额外加块、删机制、清零冰数或造非空间staging凑数。已核定的冰与外壳同体等承载关系不因阶段调整而自动获准拆散。
4. **运行逻辑与合法组合不变。** 提前到开局的冰块仍保留应有冰数；炸弹仍从其可操作时按统一时钟计时；生成器队列禁冰、彩色地格关禁外壳、出口配额、真实覆盖区和无碰撞等规定仍有效。若出现阶段调整导致数量、空间、组合或可解性冲突，应重排或报告，不自行放宽其他规则。
5. **证据与范围。** 首次引入表须有来源证据，既核对首次出现关，也核对此前关卡不存在该机制；未知不算不存在，某一子区间的首次不等于全季首次。来源事实保留原出现阶段，候选的开局提前另行记录，不反向修改竞品来源。Lv1–20含2/5互换仍不在本批重做范围；若其已存在的安排与全季首次要求冲突，单独报告并等用户授权，不擅自回滚或声称全季通过。
6. **变更后重验。** 调整承载块阶段会影响开局统计、同色相邻、冰数推进和通关路线。须基于完整新候选重跑静态、模型、真实输入、难度下界及时间/三星验证；旧阶段绑定的证据不得直接沿用。

## 开局满铺

1. **首个可操作稳定画面必须满铺。** 沿用开局统计时点：初始化自动投放、揭层及相关动画结束后，再按实际稳定状态检查。每一个可玩格必须由可见色块的实际足迹或尚未揭开的真实卷帘区域覆盖，不留裸露可玩格。
2. **卷帘算覆盖。** 只计算有真实隐藏块、有效空间区域且尚未揭开的实体卷帘；揭开的卷帘不再充当覆盖。卷帘下隐藏块仍须完整位于本卷帘内，但不额外要求填满卷帘区域；本次没有授权增加块数来填空。
3. **按格验证，不用装饰凑数。** 冰冻但可见的块计入；尚未显示的隐藏/队列块不当作可见覆盖，异形块只计实际占格而不计包围盒。外壳与内芯的同一足迹只计一次。空地格、门、生成器外框、背景图和额外墙体不能充当满铺覆盖物。不同可见块与卷帘之间仍不允许非法重叠。
4. **其他硬规则不放宽。** 维持已核定的棋盘宽高、开局/全关块数、机制数量和关键数值、卷帘隐藏批量、原创对称连通无内部孤岛墙、相邻异色及两项异形块比例等要求。可以在授权的原创设计范围内重排几何和形状，不通过删块、加块、假卷帘或非空间隐藏凑满铺。
5. **满铺不等于可解或难度达标。** 若开局没有合法推进动作或后续死锁，应重排或报告；可行解、真实输入回放、必要腾挪下界和时间三星仍分别验证。满铺仅约束首个可操作稳定画面，不要求玩家每步后重新填满。
6. **范围与看图顺序。** 适用于本轮新版Lv21–200生成，先落实21–30布局图；不因此改正式LEVELS或Lv1–20。用户要求先核对开局图片时，可提交明确标为未验证通关/难度的布局草案；看图认可不能替代后续完整门禁或正式替换授权。

## 15项机制

| ID | 机制 | 正式规则 |
|---|---|---|
| M01 | 色块生成器 | 固定队列和完整落点；落点全空即投放，不要求额外操作、不按时间、不以消除为前提。堵塞不扣数、不换位置。下一块条件仍满足时继续检查并投放，不加“每次操作最多一块”的额外限制。最终足迹须包含机口中心相邻格；通常刚生成的块占位会阻止下一块。队列禁冰；机器位于真实边缘、不与出口或其他机器重叠。 |
| M02 | 轴向块 | 仅沿指定横/纵轴双向平移，出口方向同样受限。不是旋转按钮。 |
| M03 | 钥匙与锁 | 钥匙块完全移除，同钥匙组的所有锁减1；剥层不解锁；锁归零可操作。钥匙组与承载块的出口颜色独立。 |
| M04 | 星标块与星门 | 星块只能走同色星门，普通块也可走同色星门；星块离场不把星门变成普通门。有对应星块时允许一扇普通门与一扇同色星门配对，不允许同类同色重复。 |
| M05 | 翻转门 | 整块消除或剥层成功后，所有翻转门各切换一次，包括本次出块门。开变关、关变开，门色不变；普通移动/失败操作不触发。 |
| M06 | 彩色地格 | 仅当前外层颜色相同的块可以进入；不自动消除、不变色；地格持续存在。有地格的整关禁止外壳块，含隐藏及队列。 |
| M07 | 炸弹 | 色块解除冰冻、锁定、隐藏/队列等限制而可操作后才开始计时；关卡暂停时不计时；到0未解除则失败。绑定当前外壳，剥掉外壳即解除计时和标记，内芯不继承；无外壳时随本体移除解除。 |
| M08 | 卷帘门 | 每次整块消除或剥层减1，归零后揭露覆盖区内整组块。移动不减。绘制与实际阻挡共用同一区域，每个所属隐藏块的完整足迹都须位于区域内，不要求把区域填满。不覆盖无关开局块，不同实体卷帘不重叠；必须有外部推进路径，不以互相等待解锁造成死锁。 |
| M09 | 电梯 | 固定区域全部腾空后揭露下一层；不是搬运平台。检查当前任意可见块的实际足迹，部分重叠也阻挡；移出区域即可，不要求整块消除。揭层必须先检查将要显示的全部足迹无碰撞。 |
| M10 | 普通出口 | 匹配当前外层色。真实前沿贴口之外，还须完整横截面落在单个门口内，宽块不得以细柄钻窄门，不拼接多个口放行。适用于普通/冰冻/星/翻转门和凹边出口。 |
| M11 | 异形色块 | 保持形状整体平移，不能旋转、拆分；碰撞按实际格子而非矩形包围盒。 |
| M12 | 异形棋盘 | 每个占格必须可玩，不能越过缺口或分隔缝。生成形状原创、至少左右或上下对称，宽高与竞品一致，无内部孤立阻挡。 |
| M13 | 冰冻出口 | 冰数大于0不可用；每次整块消除或剥层减1。 |
| M14 | 数字冰块 | 冰数大于0不可移动/消除；可见冰块在其他块整块消除或剥层时减1。允许藏在卷帘/电梯中；未显示前不减数，揭开当次不追扣，从下一次有效清除开始。生成器队列继续禁冰。 |
| M15 | 外壳块 | 最多外壳+本体两层且异色；剥壳后位置、形状保留，颜色改为本体。剥壳算一次清除，但不是本体移除。 |

开局已可操作的炸弹在关卡正式可操作、统一计时开始时立即倒计时，不等待第一次有效拖动；进场动画、教学遮挡或暂停未解除前不计入可操作时间。解除冰冻/锁定/隐藏限制当帧不得追扣此前不可操作的时间。

炸弹的 `enable` 指机制可操作状态，不要求玩家先选中该块，也不要求它当前存在通往出口的路线。新规则不保留“数字归零但只是装饰”的炸弹行为。

## 候选生成硬门禁

- 输入先固定竞品关卡宽高、开局/全关块数、机制种类/数量/关键数值，以及有证据的机制首次引入关卡；缺证据或冲突必须报告，不猜数、不偷减。
- 按上文首次引入合同核对关卡编号；同关允许机制提前到开局，不新增关内秒数/步数一致要求。开局与隐藏阶段的机制承载分布可重排，其余数量、空间和玩法门禁仍须独立通过。
- 棋盘原创且左右或上下对称、单一连通，无内部孤岛墙；机制数量与合法位置优先于色块摆放。
- 异形块占比分别对开局和全关检查：不超过30%，按块数计，不按占格数；完整矩形不算异形。
- 外壳与本体算同一块；全关块数包括开局、隐藏和队列内的全部独立块，不能把剥层算成新增块。开局统计时点固定为初始化自动投放/揭层及相关动画全部结束后的首个可操作稳定画面：排除仍隐藏的块和仍在队列的块，已投放或已揭开的块计入开局。不得按原始blocks数组数量或动画中间帧凑数。
- 所有出口类型及实体口合并检查颜色配额：每色最多一扇非星门；有对应星块时可再有一扇同色星门，同类同色不得重复。未获授权的竞品出口数量冲突须报告，不删门。第26关仅适用上文已批准的普通门数量重配特例。口宽须支持对应形状。
- 开局所有可见不同块正交相邻必须异色；不包含隐藏/队列，不约束玩家移动后状态。
- 首个可操作稳定画面满铺：逐格核对可见块实际足迹与未揭开真实卷帘区域的并集等于可玩格集合；揭开卷帘、装饰、隐藏/队列本体不得用于掩盖空格。满铺和无重叠分别核验。
- 禁止额外非空间 staging 减少开局数量。仅允许有真实机制依据的隐藏。
- 每10关节奏：普通、普通、困难、普通、困难、普通、普通、困难、普通、超难。
- 必要腾挪下界：普通10、困难15、超难20。必要腾挪定义为所有无道具通关路线中，“既未消除整块、也未剥层”的有效拖动次数的最小值；一次连续拖动无论经过多少格、是否转弯都只计一次；无效尝试不计有效拖动。不能直接用总拖动减清除数替代，除非已证明两者在该操作模型下等价。完成路线只证明可解，不证明最少腾挪；预算耗尽为未知，不是通过。
- 新布局重新计算时间和三星目标，必须存在同一条无道具路线能同时满足拖动与时间目标。最终时间系数须经过样本试玩标定，暂不凭旧证书自动批准。
- 三星条件文案固定为“通过关卡”“x次拖动内完成”“x秒内完成”，x为该关验证后确定的具体数值，不使用统一猜测值。
- 候选必须绑定规则版本、种子、数据哈希、工具版本、静态检查、模型回放、下界证书；任何数据改变使旧证书失效。
- 通过全部门禁后才能生成供验收版本；用户批准前不得写入正式 LEVELS。

## 已被取代的旧口径

- “隐藏里禁冰”已被取代：现在允许隐藏冰，但显露前不减数字；队列禁冰仍有效。
- “翻转门剥层不切换”及“本次使用的门不切换”已被取代：现在剥层也使全部翻转门切换，包括当前门。
- “炸弹继承给内芯”不采用：炸弹绑定外壳，剥壳后解除。
- “卷帘只统计整块消除”不采用：剥层也减数。
- “生成器必须等下一次成功操作/每动作最多一块/按时间生成”不适用于新版。
