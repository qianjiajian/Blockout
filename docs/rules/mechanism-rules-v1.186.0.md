# 福利站满体力广告奖励可溢出 v1.186.0

- Rule ID: blockout-rules-v1.186.0
- Runtime profile: revised-2026-09-27-v1.5
- Frozen on: 2026-10-10
- 完整承继v1.185.0及历史合同；仅以下体力广告领取资格取代v1.184要求开始领取时不足5的限制。

用户明确：“体力已满时，通过看广告可以超出体力上限”。

- 福利站体力奖励在5点已满或已超过5点时仍可主动观看广告领取，每次完整观看并确认保存后增加1点；例如5→6、6→7。不裁剪回5，也不在重载或自然恢复时丢弃超出部分。
- 每日2次体力奖励、四类奖励共用60秒冷却、北京时间零点刷新和真实广告完成回调要求保持。提前关闭、无填充或错误均不发奖、不扣次数；同次奖励的保存拒绝/未知沿用同一候选重试，不再看广告或重复发放。
- 5点仍是自然恢复上限；满或超出时不继续自然恢复。关内消耗、金币补满及其它经济规则保持，不将自然恢复上限整体提高。
- 广告位尚未创建，维持空ID与广告暂不可用；本地验证使用明确模拟宿主，不冒称微信真广告通过。只更新本地Web，不自动微信打包、上传或发布，不访问真实玩家存档。
