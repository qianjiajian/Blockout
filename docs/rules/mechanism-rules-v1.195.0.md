# 本省对手参与全国榜选入 v1.195.0

- Rule ID: blockout-rules-v1.195.0
- Runtime profile: revised-2026-09-27-v1.5
- Frozen on: 2026-10-10
- 完整承继v1.194.0及历史合同，仅修正v1.188中本省补充对手不参与全国榜造成的跨榜遗漏。

用户反馈：本省第一46星，全国第四也是46星，却在全国榜找不到本省第一。

## 同一身份与统一入榜

- 全国候选由原99名全国基础对手与玩家已确认省份的99名本省对手按稳定ID合并去重，共195或196个候选；不生成全部34省对手，不依赖玩家星数决定对手进度或入选。
- 候选采用同一时刻的累计星数降序、稳定ID升序排列，先选前99名对手，再加入玩家并按原同分玩家优先规则形成100人展示榜。省榜和周榜原99名本省名单保持；周榜继续按本周新增星数排序。
- 本省对手不再因只存在于本省补充名单而被全国候选遗漏。凡比分数与同分次序下全国最后入选对手更靠前的本省对手必须入选；并非强制全部本省99人永远同时显示在全国榜。相同星数的截断仍用同一稳定次序，不伪造唯一名次或插入超过100人。
- 同ID在各榜使用同一名称、头像框、类型、初始进度和按小时增长轨迹；不通过改分、换名或重设起始时间修复缺失。全国基础池原20/30/35/14类型分布保持，最终选入99人的类型比例可随真实候选进度变化。
- 对同时展示的对手及玩家，本省名次数字不大于全国名次数字。个人资料“关卡排名”与成功后主线排名变化动画使用相同省份和时间口径的全国榜；规则调整本身不触发通关晋升动画。
- 未识别且未确认保存省份时，全国暂用原99名基础对手，不借默认北京补充；保存实际识别或随机省份后采用对应省候选。已有省份保存/失败兜底和未知事务保持。

## 范围与验收

- 原独立日配额/小时频率、每关得星、200关与600星上限、周界、存档和玩家数据保持。全国展示成员可因竞争排名改变，不再承诺全国永远显示原99个基础身份。
- 验证34省多时刻/满星、未确认省、同分截断、全国选入与玩家星数无关、全部交集身份与积分一致，以及省榜高分本地身份在全国可找到；界面真实切换和滚动仍100人。
- 仅本地Web更新，不访问真实玩家存档，不微信打包、上传或发布。旧规则正文/hash和旧验收报告保持，不能把旧的跨榜遗漏测试结果重标为已修。
