# 项目立项简报

## 产品一句话

“脑王的诞生”是一款单手竖屏颜色滑块益智游戏：玩家在倒计时内整理拥挤的多格方块，把它们依次从同色边缘出口推出。

## 目标用户与首局目标

- 面向喜欢颜色分类、华容道和短局脑力游戏的微信用户。
- 新用户 30 秒内理解“拖动—对色—出门”。
- 首次 3 分钟内完成前三关，并看到至少一种需要改变出块顺序的局面。

## 核心循环

观察出口与堵塞关系 → 拖动方块腾挪 → 对齐同色出口并推出 → 解锁/融化下一层障碍 → 清空棋盘 → 获得金币并进入下一关；金币可按需补充三类道具，形成克制的长期容错循环。

## 范围与验收

- 竖屏 Canvas 2D，以 720×1584（5:11）作为正式界面与截图基准；内部交互坐标通过双轴映射适配不同微信设备，并继续覆盖 320×568 小屏。
- 100 个重新设计的数据驱动关卡全部具有标准解法测试，并按十章引入和组合机制。
- 首次有效移动才开始计时；倒计时归零失败，清空全部方块成功。
- 方块只平移、不旋转、不重叠；拖动表现按像素连续跟手并支持斜向双轴移动，规则层只接受真实经过的相邻格，不自动绕障碍寻路。
- 完整方块在拖动中贴边并完全落入当前外层颜色对应的可用出口跨度后立即自动消除，无需松手或继续向外拖。错色、冰封、星标不匹配或无出口边缘均不触发。
- Web 预览与微信小游戏共用规则/渲染层，仅平台 API 适配不同。
- 首页可在开局前调整声音、触觉和简化动效；暂停页读取并修改同一份本地设置。设置页可二次确认清除全部玩法进度，同时保留这三项设备偏好。
- 微信主包小于 4 MB，关闭生产 sourcemap，隐藏状态栏，锁定 portrait。
- 每次有效完成普通关都发放当前关 `level.reward` 基础金币；是否首通只影响进度解锁，最佳步数、三星和章节成就继续持久化。
- 金币可在单页补给站购买加时、火箭和脉冲；单件购买、固定价格、库存上限 9，余额不足或已满时不得扣款。
- 首页不提供每日任务入口、发现徽章或点击热区；旧存档中的相关字段仅用于兼容读取和异常中断返还，不构成可进入的玩法模式。
- 红蓝绿黄等颜色同时使用圆、菱形、三角形、方形等标记，不只依赖色相。

## 原创与合规边界

仅参考抽象玩法、反馈节奏与难度递进。不得使用原视频中的名称、Logo、角色、原始美术、关卡坐标、广告素材或商店文案。当前首页采用原创“霓虹物流分拣实验室”，所有 100 关重新设计并以自动测试验证。

## 主要风险

- 拖拽手感：以真实 Pointer E2E 和选中/出口关键帧验收。
- 关卡死局：每关同时维护标准解法并由独立 A* 求解器验证，模型层与真实指针层均为 100/100 通过。
- 微信兼容：生产代码无 DOM 依赖，通过 Host 隔离 wx API。
- 安全区：HUD/道具随 safeArea 位移；仍需多台真机复核。
- 首次反馈舒适度：首页设置无需先启动倒计时，简化动效继承系统偏好；仍需真机验证不同音量、马达和系统中断。
- 色觉可达性：八色确定性矢量双编码、双层前后层标记及本地灰阶/红绿色弱模拟均已通过；仍需色弱玩家与真机验证实际对比度。
- 经济膨胀：固定经济报告只统计每关各完成一次的基准金币，重复完成属于可持续产出、不计入有限总额；固定单价与库存上限仍形成静态约束，需用真实玩家的复玩频率验证 180/240/210 的消耗感受。
- 商业发布：AppID、主体认证、隐私协议、软著、年龄分级和广告能力不在本地代码可完成范围内。
