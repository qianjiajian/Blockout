# 方块出逃（微信小游戏竖屏正式版工程）

一款原创视觉的竖屏颜色滑块益智游戏。玩家拖动多格方块，在异形棋盘内避让其他方块与外轮廓；完整方块一旦在拖动中对齐可用同色同图形出口边缘便会立即送出，无需松手。项目包含 Web 预览入口和微信小游戏原生 Canvas 2D 构建入口。

## 已完成

- 100 个全部重做且布局唯一的可解关卡，形成十章锯齿式难度曲线；每关拥有独立真实碰撞轮廓，覆盖沙漏、阶梯、双舱、窄桥等 12 个异形棋盘族及 1 个教学矩形族，共 13 个轮廓族。异形只从外沿塑形，棋盘内部不放静态障碍或封闭死格。除基础/机制教学位外，从第 3 关开始必须先停车让路；章末必要腾挪按 `2/2/2/2/2/3/3/3/4/4` 递增。
- 完整混合拖拽、连续扫掠碰撞、贴墙滑动、同色出口边缘按住即自动送出、撤销、重开、暂停与本地存档。
- 微信触摸层锁定最先按下的主手指；第二根手指、乱序 `changedTouches` 和非主手指抬起不会抢走或中断拖拽，切后台会同步释放宿主与游戏两层触点状态。

## 本地运行

```powershell
pnpm install
pnpm art:optimize
pnpm dev
```

浏览器打开 `http://127.0.0.1:5173/`。测试与构建：

```powershell
pnpm test
pnpm docs:levels
pnpm docs:economy
pnpm levels:freeze:verify
pnpm verify:system-only
pnpm build
pnpm release:verify
pnpm wechat:verify
```

`levels:freeze:verify` 是纯系统迭代的可选关卡锁。只有在获准的关卡修改已完成、全季 Pointer 与文档门禁均确认通过后，才可显式运行 `pnpm levels:freeze:capture -- --confirm --label=<快照名>` 重建基线；每次捕获还会在 `playtest-results/level-freeze-baselines` 留下不可覆盖的同名归档。普通构建与 `pnpm verify` 不会自行改写该快照。

首次运行浏览器回归前安装 Chromium，然后可一键执行完整验收：

```powershell
pnpm exec playwright install chromium
pnpm verify
```

原创关卡生产链可通过 `pnpm levels:original:pipeline` 重新导出：它会按 Block Out 专用的“缓冲紧张度 / 隐藏信息 / 机制多样性 / 出口竞争”公式评分，拟合新版竞品 Lv1–100 曲线，合并正式求解证据，并执行旋转、镜像和换色均无法绕过的原创性门禁。流程与生成模板分别见 [原创关卡生产流程](docs/blockout-original-level-pipeline.md)和 [原创关卡 Prompt 模板](docs/blockout-original-level-prompt-template.md)。

`pnpm verify` 会先检查 ImageGen 运行素材的路径、尺寸、Alpha、图集格数、顺序、清单覆盖与发布显示密度，再依次运行 TypeScript、关卡设计与经济报告漂移检查、61 个文件共 467 项规则/关卡/每日挑战/机制事件/道具/微信触摸/自适应热区测试、完整 64 套真实指针浏览器回归（含五档难度现场复算与代表截图、收藏/每日挑战一次性发现提示、每日挑战持续前台跨午夜刷新、旧日进行中挑战的开始日/模型/结算归属保护、首次隐藏启动、`onHide` 取消监视与 `onShow` 重建，以及 16/76 张首屏分层加载、6 路并发上限、慢资源/资源失败恢复、完整停靠位 A* 现场求解、完整混合拖拽、排行榜、五页导航、三态事务存档、低端性能与内存生命周期）。全季回归后会用刚生成的 Pointer 证据刷新并二次校验关卡设计与经济报告，再完成 Web 与微信构建，因此命令结束后不会留下“测试已更新、文档仍旧”的漂移状态。需要在纯系统迭代中禁止任何关卡与难度语义变化时，改用 `pnpm verify:system-only`；普通 `verify` 与构建允许已授权的关卡设计对话更新关卡。工作区已在 `pnpm-workspace.yaml` 中仅允许 esbuild 的必要安装脚本。

## 棋盘造型编辑器

运行 `pnpm board:editor`，即可在第 1–100 关之间切换，用“铺地/挖空”拖动小格拼出异形棋盘。黄色必需格受保护，挖空区必须连到棋盘外沿，编辑器会拒绝内部封闭死格；工具支持撤销/重做、本地草稿、JSON 导入导出、正式 A* 可解性验证，以及验证通过后直接写回项目。写入前会自动备份，并同步当前轮廓下的最少拖动数。完整说明见 [棋盘造型编辑器](docs/board-shape-editor.md)。

- `src/core`：与渲染无关的关卡和规则模型。
- `src/game`：Canvas 2D 游戏界面与交互。

- `src/platform`：Web/微信小游戏平台适配。

- `public/assets/art`：按 `backgrounds / gameplay / ui / fx` 分类的运行时 ImageGen 素材。
- `references/benchmark/video/1fps`：原玩法视频逐秒截图，共 760 张。

- `dist-wechat`：可导入微信开发者工具的构建产物。
- `release-assets`：ImageGen 上架图标、商店截图与上架文案。
