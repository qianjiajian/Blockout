# Formal star-block overlays

The gold triangle marks are transparent overlays for star-marked blocks. They
are drawn above the ordinary colour block, so colour and shape remain authored
by the existing formal block set and can still be replaced independently.

The filenames follow the project's formal shape ids: 1, 2, 3, 8, 9, 4, 5,
6 and 7 respectively (single, vertical bars, horizontal bars, L/S/T and
square). The overlays are intentionally limited to the supplied nine shapes;
unsupported future shapes keep the existing atlas fallback mark.
