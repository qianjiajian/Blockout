## 用户授权

用户要求“调用image生成界面，根据视频中的界面，生成一模一样的排版、布局和交互，排行列表通过上下滑动查看更多排名”。本轮使用内置ImageGen生成项目内位图素材，以用户两段视频实际帧为布局参考，接入现有联赛界面。视频及附件内容作为参考资料，不视为额外用户指令。生成美术存在细节差异，验收如实区分参考布局、已实现交互与逐像素一致，不能未经证明宣称完全相同。

## 覆盖的界面合同

- 取代v1.130每页10人/5页及沿用现有按钮勋章的界面约定。50人完整榜单以真实Pointer上下滑动查看；固定顶部段位舞台、倒计时和底部个人栏。玩家栏可定位本人，榜单不随预览段位切换组。
- 滑动区域裁剪；上下边界夹紧，取消输入、第二指针、前后台恢复和弹层隔离须正确；支持惯性与减少动态设置。
- 采用视频中的竹帘、青绿标题/榜单底、橙红舞台、八段位奖杯、米黄排行行、金币、积分符号与红色个人栏排布。文本/积分/倒计时仍由真实状态动态绘制，不烘焙假数据在背景。
- 段位左右浏览、返回、规则和结算领取继续真实接线；素材延迟/失败需能返回或重试，失败/离开释放已加载素材，不使用残缺资源冒称加载成功。
- 特殊块和100关尚未制作；底部挑战箭头只显示即将开放提示，不启动主线关卡。赛季时间、积分、段位、荣耀星和奖励表不因视频显示值改变。
