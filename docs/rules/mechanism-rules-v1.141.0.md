# 新用户初始金币调整 v1.141.0

- Rule ID: `blockout-rules-v1.141.0`
- Runtime profile: `revised-2026-09-27-v1.5`
- Frozen on: 2026-10-03
- 完整承继 v1.140 及全部历史合同。本轮只调整新用户首次创建存档时的金币余额；已有玩家存档、关卡奖励、道具价格、补给经济和结算规则保持不变。

## 用户授权

用户要求：“新用户进入游戏，初始金币改为0”。本版本将“新用户”限定为设备上没有可恢复的有效游戏存档、需要创建默认存档的情况；不把该要求解释为重置或追溯修改已有玩家余额。

## 新用户默认余额

- 新建默认存档的 `coins` 初始值为 `0`。
- 缺少金币字段或存档无法恢复时，使用新默认值创建安全存档；首次进入游戏不自动补发金币。
- 有效旧存档中的 `coins` 原值必须保留，不因升级、重新加载或迁移被重置为0；已有玩家继续沿用原奖励、消费和补给规则。

## 验收边界

- 必须通过新用户缺少存档时余额为0的存档初始化回归测试。
- 必须通过已有有效存档金币保持不变的回归测试，并通过TypeScript检查、Web构建和规则锁校验。
- 本轮不改关卡、星级、道具、奖励或存档迁移以外的经济逻辑，不打包、上传或发布。
