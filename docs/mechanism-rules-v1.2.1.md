## 本版本的确认依据与差异

v1.2.1仅纠正v1.2.0“范围和发布顺序”中的旧profile示例，将其与已确认的v1.2运行时标识统一；玩法和用户授权不变，运行时仍为`revised-2026-09-21-v1.2`。已锁定的v1.2.0原文及manifest条目保留，不原地修改。

本版本继承 v1.1.0 的机制、时钟、开局统计、必要腾挪定义和门禁；v1.0.0/v1.1.0 正文与已有manifest条目保留不改。纳入用户在2026-09-21明确确认的两条变更：

- 出口同色例外：有对应星块时，只允许“一扇普通门＋一扇同色星门”。同色两扇普通门、同色两扇星门仍禁止。冰冻、翻转是出口的附加属性，不产生额外同色名额。对应星块可在开局、真实隐藏层或合法队列中，其外层/内层需要该星门颜色；不得新增假星块、空星门或多portal来绕过重复颜色检查。
- 第26关特例：不使用竞品的11个实体出口，也不扩展8色色板。用户允许保留3个冰冻出口及初值5、9、14，重新配置普通出口数量，由生成和验证确定最终数量。本关没有来源星块/星门，不得为突破颜色限制自行新增星机制；因此总实体出口最多8，普通出口为1–5。其他关不因此获得删门或重配机制数量的授权，第26关其他机制数量/数值、宽高、开局/全关块数要求不变。
- 来源事实与设计特例分开记录：竞品Lv26仍为8普通+3冰门，不能把来源数据改成候选出口数；候选合同注明本版本批准的普通出口重配特例。原始事实错误的证据修订也不等于修改竞品或正式关卡。

“普通门”在同色配额中指非星标出口（包括非星标的冰冻/翻转出口）。单个逻辑门若有多个实体口，每个实体口分别占用配额。星块仍只能通过同色星门，普通块仍可通过同色星门。

这两条变更不自动迁移旧关卡、不批准尚未验证的候选，也不构成放宽10/15/20必要腾挪下界的授权。

## 范围和发布顺序

1. 规则与验收用例定稿。
2. 在独立小关卡中实现、测试机制。
3. 建立候选生成前置合同及静态、求解、回放、下界证明检查。
4. 试制 Lv21–30，提交试玩和对比材料，用户验收后再每10关推进到200。

新生成范围为 Lv21–200；Lv1–20（含已完成的第2/5关互换）不因本规则重做。本批不修改正式 LEVELS 或用户存档，不覆盖原始文档、视频、素材。新机制使用 `mechanismRules: "revised-2026-09-21-v1.2"` 显式启用；未标记的历史关卡保持兼容。此隔离是过渡措施，不是宣布正式200关已经修复。

## 15项机制

| ID | 机制 | 正式规则 |
|---|---|---|
| M01 | 色块生成器 | 固定队列和完整落点；落点全空即投放，不要求额外操作、不按时间、不以消除为前提。堵塞不扣数、不换位置。下一块条件仍满足时继续检查并投放，不加“每次操作最多一块”的额外限制。最终足迹须包含机口中心相邻格；通常刚生成的块占位会阻止下一块。队列禁冰；机器位于真实边缘、不与出口或其他机器重叠。 |
| M02 | 轴向块 | 仅沿指定横/纵轴双向平移，出口方向同样受限。不是旋转按钮。 |
| M03 | 钥匙与锁 | 钥匙块完全移除，同钥匙组的所有锁减1；剥层不解锁；锁归零可操作。钥匙组与承载块的出口颜色独立。 |
| M04 | 星标块与星门 | 星块只能走同色星门，普通块也可走同色星门；星块离场不把星门变成普通门。有对应星块时允许一扇普通门与一扇同色星门配对，不允许同类同色重复。 |
| M05 | 翻转门 | 整块消除或剥层成功后，所有翻转门各切换一次，包括本次出块门。开变关、关变开，门色不变；普通移动/失败操作不触发。 |
| M06 | 彩色地格 | 仅当前外层颜色相同的块可以进入；不自动消除、不变色；地格持续存在。有地格的整关禁止外壳块，含隐藏及队列。 |
| M07 | 炸弹 | 色块解除冰冻、锁定、隐藏/队列等限制而可操作后才开始计时；关卡暂停时不计时；到0未解除则失败。绑定当前外壳，剥掉外壳即解除计时和标记，内芯不继承；无外壳时随本体移除解除。 |
| M08 | 卷帘门 | 每次整块消除或剥层减1，归零后揭露覆盖区内整组块。移动不减。绘制与实际阻挡共用同一区域，每个所属隐藏块的完整足迹都须位于区域内，不要求把区域填满。不覆盖无关开局块，不同实体卷帘不重叠；必须有外部推进路径，不以互相等待解锁造成死锁。 |
| M09 | 电梯 | 固定区域全部腾空后揭露下一层；不是搬运平台。检查当前任意可见块的实际足迹，部分重叠也阻挡；移出区域即可，不要求整块消除。揭层必须先检查将要显示的全部足迹无碰撞。 |
| M10 | 普通出口 | 匹配当前外层色。真实前沿贴口之外，还须完整横截面落在单个门口内，宽块不得以细柄钻窄门，不拼接多个口放行。适用于普通/冰冻/星/翻转门和凹边出口。 |
| M11 | 异形色块 | 保持形状整体平移，不能旋转、拆分；碰撞按实际格子而非矩形包围盒。 |
| M12 | 异形棋盘 | 每个占格必须可玩，不能越过缺口或分隔缝。生成形状原创、至少左右或上下对称，宽高与竞品一致，无内部孤立阻挡。 |
| M13 | 冰冻出口 | 冰数大于0不可用；每次整块消除或剥层减1。 |
| M14 | 数字冰块 | 冰数大于0不可移动/消除；可见冰块在其他块整块消除或剥层时减1。允许藏在卷帘/电梯中；未显示前不减数，揭开当次不追扣，从下一次有效清除开始。生成器队列继续禁冰。 |
| M15 | 外壳块 | 最多外壳+本体两层且异色；剥壳后位置、形状保留，颜色改为本体。剥壳算一次清除，但不是本体移除。 |

开局已可操作的炸弹在关卡正式可操作、统一计时开始时立即倒计时，不等待第一次有效拖动；进场动画、教学遮挡或暂停未解除前不计入可操作时间。解除冰冻/锁定/隐藏限制当帧不得追扣此前不可操作的时间。

炸弹的 `enable` 指机制可操作状态，不要求玩家先选中该块，也不要求它当前存在通往出口的路线。新规则不保留“数字归零但只是装饰”的炸弹行为。

## 事件结算和验收用例

| 用例 | 输入/边界 | 必须成立 |
|---|---|---|
| A01 | 剥一层/移除一个本体 | 翻转门全体恰好切换一次；冰门和可见冰块各减1；卷帘各减1；不因显露内芯额外计数。 |
| A02 | 钥匙块剥层，然后本体移除 | 先不解锁，后只减匹配组；其他组不变。 |
| A03 | 冰6藏在计数1的卷帘下 | 外部清除揭开后仍冰6；下一次清除才冰5。 |
| A04 | 冻结/上锁/隐藏/队列中的炸弹 | 时间不减少，不会在不可操作期间判失败；解除最后一个限制后开始；未选中过也计时。 |
| A05 | 炸弹外壳剥除 | 内芯保留、计时字段/标记解除，不再因旧计时失败。 |
| A06 | 所有翻转门初始开关不同；使用其中一扇剥层 | 当前门和其他门都翻转；无效出口尝试不切换。 |
| A07 | T形细柄贴1格门，身体宽3 | 拒绝；换成覆盖完整宽度的门接受。四向、偏移、凹边口、星/冰/翻转门均覆盖。 |
| A08 | 同色块进入地格/异色块尝试进入 | 前者占位但不消除，后者被拒绝；有地格+任意外壳的关卡在构造前拒绝。 |
| A09 | 机器目标被一格挡住，再移动腾空 | 阻挡时队列不变；完整腾空即出下一块，不等下一次操作；中心口出块，无远端搜索。 |
| A10 | 机器开局空口、堵塞、两机竞争同格 | 空口能出货；每次成功释放更新库存；竞争不重叠、失败者不扣数。 |
| A11 | 拖动腾空后生成，再取消触控/撤销 | 玩家事务及派生投放原子一致；不丢块、不重复、不形成非法重叠。取消不是恢复已消耗的墙钟时间。 |
| A12 | 时间生成器在拖动中出货后取消 | 历史兼容路径必须保留自主事件或明确安全处理，不得出现库存/时间不一致。 |
| A13 | 电梯原始成员已移出，但外来块部分压住 | 不开；外来块完全移出后开；不以初始成员ID消失代替占位检查。 |
| A14 | 隐藏层即将揭开，有无关活动块占位 | 等待，不产生两块同格；多块同层整体释放，不部分穿插。 |
| A15 | 失败、完成、暂停后的操作与计时 | 不发生继续投放、二次翻转、计数穿零或重复结算。 |
| A16 | 快照/克隆/撤销/求解器回放 | 含炸弹、队列、揭层、门开关的状态一致；新规则未支持的证明工具不得发合格证。 |

先按可见性快照扣冰，再处理本次卷帘揭开，因此新露出的冰不追扣。揭层、投放在同一确定性空间检查中串行处理，必须终止且无重叠。视觉动画只表现模型结果，不另行扣数或解除机制。

## 候选生成硬门禁

- 输入先固定竞品关卡宽高、开局/全关块数、机制种类/数量/关键数值；缺证据或冲突必须报告，不猜数、不偷减。
- 棋盘原创且左右或上下对称、单一连通，无内部孤岛墙；机制数量与合法位置优先于色块摆放。
- 异形块占比分别对开局和全关检查：不超过30%，按块数计，不按占格数；完整矩形不算异形。
- 外壳与本体算同一块；全关块数包括开局、隐藏和队列内的全部独立块，不能把剥层算成新增块。开局统计时点固定为初始化自动投放/揭层及相关动画全部结束后的首个可操作稳定画面：排除仍隐藏的块和仍在队列的块，已投放或已揭开的块计入开局。不得按原始blocks数组数量或动画中间帧凑数。
- 所有出口类型及实体口合并检查颜色配额：每色最多一扇非星门；有对应星块时可再有一扇同色星门，同类同色不得重复。未获授权的竞品出口数量冲突须报告，不删门。第26关仅适用上文已批准的普通门数量重配特例。口宽须支持对应形状。
- 开局所有可见不同块正交相邻必须异色；不包含隐藏/队列，不约束玩家移动后状态。
- 禁止额外非空间 staging 减少开局数量。仅允许有真实机制依据的隐藏。
- 每10关节奏：普通、普通、困难、普通、困难、普通、普通、困难、普通、超难。
- 必要腾挪下界：普通10、困难15、超难20。必要腾挪定义为所有无道具通关路线中，“既未消除整块、也未剥层”的有效拖动次数的最小值；一次连续拖动无论经过多少格、是否转弯都只计一次；无效尝试不计有效拖动。不能直接用总拖动减清除数替代，除非已证明两者在该操作模型下等价。完成路线只证明可解，不证明最少腾挪；预算耗尽为未知，不是通过。
- 新布局重新计算时间和三星目标，必须存在同一条无道具路线能同时满足拖动与时间目标。最终时间系数须经过样本试玩标定，暂不凭旧证书自动批准。
- 三星条件文案固定为“通过关卡”“x次拖动内完成”“x秒内完成”，x为该关验证后确定的具体数值，不使用统一猜测值。
- 候选必须绑定规则版本、种子、数据哈希、工具版本、静态检查、模型回放、下界证书；任何数据改变使旧证书失效。
- 通过全部门禁后才能生成供验收版本；用户批准前不得写入正式 LEVELS。

## 已被取代的旧口径

- “隐藏里禁冰”已被取代：现在允许隐藏冰，但显露前不减数字；队列禁冰仍有效。
- “翻转门剥层不切换”及“本次使用的门不切换”已被取代：现在剥层也使全部翻转门切换，包括当前门。
- “炸弹继承给内芯”不采用：炸弹绑定外壳，剥壳后解除。
- “卷帘只统计整块消除”不采用：剥层也减数。
- “生成器必须等下一次成功操作/每动作最多一块/按时间生成”不适用于新版。
- 只看异形块最前沿就让宽块过窄门，不符合新版完整通行宽度规则。

旧报告、旧测试、旧聊天摘要和 `.codex-temp` 中的理解笔记，只能用作历史证据，不能覆盖上述修订。用户今后明确修改规则时，以新的用户指令为准并走新版本流程，不以冻结文档拒绝用户变更。

## 尚待确认或验收的边界：不得默认为已通过

以下不改变上面的已确认规则。任何依赖这些边界的正式验收，必须先补齐口径或证据；可以做标明假设的隔离实验，但不能据此发布合格证。

1. **历史时间机器的取消/撤销**：A12是兼容性工作项，不批准时间机器进入新版。当前手势取消与跨多步撤销要分别验证，不得以一次取消通过宣称所有自主事件撤销安全。
2. **时间与三星系数**：须按新布局、无道具路线和试玩标定；目前不固定未验证系数。
3. **输入冲突**：超过现有8色及本版本星门配对容量的来源出口须报告，不擅自扩展色板或删门。第26关普通门数量重配已经批准，但具体候选数量仍须生成验证，不视为已完成。竞品颜色总数是否也须逐关完全一致，不凭出口数量要求自行推导。
