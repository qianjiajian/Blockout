# 主线首通金币40 v1.161.0

- Rule ID: blockout-rules-v1.161.0
- Runtime profile: revised-2026-09-27-v1.5
- Frozen on: 2026-10-08
- 承继v1.160及历史合同。本版仅将主线首次通关基础金币从20改为40，取代历史合同中与该数值冲突的规定；其余规则保持。

## 用户已确认范围

- 主线每关首次通关发放40金币。
- 重复通关仍发放0金币，包括重复通关补星；沿用已有首通记录，不新增可重复领取机会。
- 不追溯旧通关、不补差额、不重置或修改已保存金币与首通进度。
- 每日挑战、荣耀联赛及其它独立奖励不因本次改变。

## 实现约定

以下是落实本次奖励变更并保持既有边界的实现约定，不冒称用户逐项原话。

- 主线账户结算、胜利页金额、回到首页的金币表现及相关经济统计统一使用40金币首通标准。金币发放资格继续根据真实主线首通账本判定，不以星级提高、回看早关或临时测试制造新首通。
- 仅修改主线基础金币的账户规则，不重写冻结关卡的历史`reward`元数据，不修改关卡布局、时限、星级目标或机制规则；历史数据中的旧数值不作为实际奖励金额。
- 仍通过原候选保存事务确认奖励。保存拒绝或未知时不提前完成结算、不重复发奖；未知重试保留原baseline与完整candidate，不重新生成候选或追加40金币。变更前已创建的待确认候选按原对象核对，不追改为新金额。
- 每日挑战、联赛赛季、旅程里程碑、任务、成就及其它独立金币奖励与模式隔离保持。道具价格继续采用v1.160冻结300、火箭400、脉冲400金币，每次购买1个。

## 验证与交付边界

- 使用隔离或合成存档核验主线首次通关40、重复/补星0、失败与未知保存重试不重复发奖、表现与实际入账一致，以及每日/联赛奖励保持原配置。
- 历史规则文档、校验值、关卡元数据和既有证据不重写；本规则登记不代表实现或验证已经完成，进度另记WORKSTATE。
