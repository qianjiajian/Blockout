## 从早期视频提炼出的梯度规则

1. 第 1 关只教输入；第 2–5 关每关只增加一个主要认知变量。
2. 新机制的首关降低棋盘压力，下一关立刻与旧机制组合。
3. 异形轮廓首次出现时，必须形成共享窄颈或分区调度，不能只改变外观。
4. 恢复关可以把轮廓改回规整，但不能把策略退回“见门就出”。
5. 强峰值来自多阶段盘面变化，而不是只缩短时间。
6. 棋盘内部不放永久固定格；阻挡来自外轮廓、可移动方块与会解除的临时机制。

## 色块数量与造型节奏

逐秒首帧观察得到的不是“始终四块”，而是明显的呼吸波形：Lv1 约 2 块、Lv2 约 3 块、Lv3–5 快速上升到约 5–6 块；Lv6 新机制教学短暂降压，Lv7–9 再升到约 7–12 块；Lv10、Lv15 机制首秀再次回落，Lv17–20 的阶段考核升至约 14–20 块。数量回落承担教学或视觉休息，不能连续多关固定在同一数量。

竞品早期已经混用横/竖条、L、折钩、T、阶梯和折线块。造型不仅是装饰：长条占据公共轴线，L/T 块需要更大的转向空间，折线和钩形会改变停车位价值。因此本项目以“连通多格块”作为最小单位，不通过拆成单格来虚增数量。

本项目 100 关可见色块目标按逐关波形配置：Lv1–10 为 `2–10` 块，Lv11–20 为 `4–12` 块，Lv21–40 为 `4–11` 块，Lv41–70 为 `5–11` 块，Lv71–90 为 `8–12` 块，Lv91–100 为 `9–14` 块。机制首秀保留 4–6 块的恢复位，随后两至四关内回升；第 31 关后的高压样本为 8–12 块，不能退回固定四块。

形状池包含横/竖骨牌、三格直条、三种 L、长钩、T、折线和少量 2×2。第 3 关起，凡可见块不少于 5 个，开局至少出现 3 种形状签名；第 21–100 关每章至少覆盖 8 种形状签名，2×2 正方形占比不超过 25%。所有形状都用现有八色 ImageGen 单元块与连接件拼合，素材路径和替换协议保持不变。

## Levels 331–340：成熟期的难度维度

| 关卡 | 主要观察 |
|---|---|
| 331 | T/城堡轮廓，多侧出口和临时轨道，多个队列同时推进 |
| 332 | H/沙漏双舱，中央单一共享颈部，计数锁控制阶段 |
| 333 | 上部储备区—细长连接—下部主盘，明显的波次释放 |
| 334 | 外轮廓规整但出口计数密集，说明视觉恢复不等于策略清零 |
| 335 | 阶梯屋形盘面，钥匙块和 2/3 级锁链形成局部顺序 |
| 336 | 沙漏轮廓，高占用率、多个 5 级计数目标共同争用窄颈 |
| 337 | 规整盘面加入星标块与 4/9 级横向屏障，压力转向规则层 |
| 338 | 多分区棋盘，14 级储备区分批向主盘释放 |
| 339 | Super Hard，复杂外轮廓、中央 20 级储备与 30 级目标，多阶段叠加 |
| 340 | H/十字轮廓，四个叶片区围绕中央门格竞争共享通道 |

成熟期关卡并不是把同一谜题放大，而是在“外轮廓、占用率、共享通道、出口队列、阶段释放”之间轮换主变量。

## 本项目当前落地门槛

- Lv1–2 保持 2/3 块基础教学；Lv3–9 快速增加数量和异形块，Lv10/Lv15 等机制首秀主动降压。
- 第 31 关后的代表性高压开局含 8–12 个可操作色块；独立直出比例不高于三分之一，并保留至少一个可读起手。
- 章节清除负载中位数为 `6 → 9 → 9 → 10 → 11 → 13.5 → 13 → 16.5 → 16.5 → 19`，数量、夹层和阶段机关共同增长。
- 100 关全部使用不同外轮廓；内部永久固定格为 0，封闭死格为 0。
- 当前验收不调用完整关卡求解器；使用开局结构、单块几何路径、可逆一步移动、真实 Pointer 局部操作和竖屏截图作为证据。
