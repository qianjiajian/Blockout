## 720×1584 固定合成规范

运行时严格按 `reference.png` 的结构合成。面板、金币、按钮和关闭按钮继续使用可替换切图；标题、关卡号、三颗星和三行条件由 Canvas 动态绘制，确保每关可以显示具体的拖动/时间数值，且不需要重新导出整张面板。

| 元素 | 左上角 |
|---|---:|
| `panel.png` | (25, 287) |
| `glow.png` | (108, 398) |
| 动态标题 `settlement.levelComplete` | (360, 360) |
| 动态关卡徽章 | (242, 408) |
| 动态三颗星 | (244, 465)、(330, 457)、(416, 465) |
| 动态条件面板/三行 | (91, 528)、行首 (108, 540/608/676) |
| `coin-pile.png` | (144, 736) |
| `reward-pill.png` | (444, 806) |
| `continue-button.png` | (199, 964) |
| `close.png` | (616, 336) |

- 外围使用纯黑 `199/255` 遮罩。
- 第一行“通过关卡”始终点亮；第二行显示 `{target}次拖动内完成`；第三行显示 `{target}秒内完成`。每行根据本次结算结果显示勾选/未达成状态，星级为 1～3 颗。
- 奖励显示真实到账数字并保留 `+` 前缀；白色填充、`#415ca4` 描边。
- 按钮固定显示 `Continue`；白色填充、`#10520b` 3px 外描边。
- 标题、关卡号、条件文案和奖励数字均为动态文本；具体布局与字号集中在 `src/game/winSettlementLayout.ts`，后期替换单张资源无需改动结算规则。
- 红字与箭头属于设计标注，不进入正式画面。
