用户明确要求“生成正式关卡”。本版本把201–210十个已生成的`LevelSpec`整理为正式数据隔离包`FORMAL_ISOLATED_201_210_LEVELS`，并为每关保存正式数据状态、路线、下界和三星目标的绑定记录。这里的“正式数据”指可审计的隔离对象，不等于活动关卡发布或已完成全部运行态验收。

生产`LEVELS`、`getLevelStrict`、活动页和存档边界仍为1–200；不把201–210接入活动流程，不打包、不上传、不发布，不改玩家存档。历史兼容导出`FORMAL_201_210_LEVELS`仍只包含此前接受的201和210。
